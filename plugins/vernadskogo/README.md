# Вернадского — маркировка панелей

Отдельный плагин для **Revit 2024**. Вкладка **Вернадского**, панель **АР**, команда **Маркировка панелей**. Не зависит от TrueBIM и не ограничивает запуск по проекту.

## Использование

1. Закройте Revit 2024 и запустите `Vernadskogo-Revit2024-Setup.exe`. Установка для текущего пользователя, без прав администратора.
2. Откройте модель, в имени которой есть `_К1_`, `_К2_` или другой однозначный фрагмент `_К<число>_` (кириллическая К).
3. Откройте **Вернадского → АР → Маркировка панелей**.
4. Выберите начальное направление: юг, юго-восток, восток, северо-восток, север, северо-запад, запад или юго-запад. По умолчанию — юг.
5. Заполните номера материалов. Только цифры; разные материалы должны иметь разные номера. Новые материалы показываются с пустым номером. Ведущие нули удаляются.
6. Нажмите **Маркировать**. Существующие значения перезаписываются без предварительного отчёта и дополнительного подтверждения.

## Область обработки и результат

Все экземпляры категории «Стены» текущего документа с точными значениями параметров типа «Модель» = «Фасад», «Описание» = «Стеновая панель». Обрабатываются все стадии и варианты, включая скрытые элементы; выделение и текущий вид не влияют. Связанные модели не обрабатываются.

- **• Секция**: `К1` из имени модели `_К1_`.
- **GP_Этаж**: `13` из имени уровня `К1_Этаж 13_+46,240`. Источник — «Уровень» загружаемого семейства; при отсутствии параметра используется связанный уровень элемента `LevelId`. «Зависимость снизу» не используется.
- **Марка**: `1_1_13_7`, то есть номер материала, корпус, этаж, порядковый номер. Дополнительных нулей нет.
- **Материал несущих конструкций**: параметр типа с выбором материала Revit (`STRUCTURAL_MATERIAL_PARAM`). Один материал соответствует одной строке независимо от количества типов панелей. Параметр «Материал стен» больше не используется.

Нужны существующие параметры экземпляра «• Секция», «GP_Этаж» и стандартная «Марка». Секция и марка должны быть текстовыми. GP_Этаж поддерживает текст, целое число, число и денежную единицу. Для последних двух типов номер этажа записывается через `Parameter.Set(double)`; тип параметра и формат отображения в проекте сохраняются. Например, этаж 13 хранится как числовое значение 13, а в марку входит `13` независимо от денежного символа и десятичных знаков в интерфейсе Revit. Плагин не создаёт параметры и не изменяет параметры типов. Неопределённый корпус или этаж останавливают запуск с объяснением и идентификатором элемента, когда он известен. Если при записи Revit не позволяет изменить параметр, операция целиком отменяется.

## Порядок нумерации

Для каждого номера этажа отдельно строится охватывающий прямоугольник по габаритам панелей в плоскости XY модели. Центр прямоугольника служит началом координат обхода. Положение каждой панели — центр её габаритов на плане. Это расчётные величины: линии и другие элементы в модели не создаются.

Условный север — ось +Y модели, восток — +X. Истинный север и ориентация текущего вида не участвуют. Старт — луч выбранного направления из центра прямоугольника, далее угол возрастает против часовой стрелки: **Юг → Восток → Север → Запад**. Если панели прямо на луче нет, первой становится ближайшая по углу после него. Это старт от середины выбранного направления, а не от угла фасада.

Нумерация начинается с 1 на каждом этаже корпуса, общая для всех материалов. Уровни с одинаковым извлечённым номером этажа относятся к одной группе. При одинаковом угле сначала идёт панель ближе к центру, затем — с меньшим ElementId. Повторный запуск при неизменных данных даёт тот же порядок. Добавление, удаление и перемещение панелей может изменить центр этажа и номера.

## Сохранение соответствий

Номера материалов и последнее направление сохраняются **внутри модели через Extensible Storage**, в отдельном служебном элементе DataStorage. Новые общие или проектные параметры не добавляются; свойства панелей не засоряются. Материал определяется по UniqueId, поэтому переименование материала сохраняет соответствие. Сопоставления временно отсутствующих материалов сохраняются; при их возвращении конфликт номеров потребуется исправить в таблице.

Настройки записываются только вместе с успешной маркировкой, сохраняются на диск обычным сохранением модели и передаются вместе с RVT. Отмена окна ничего не меняет. Одно действие Undo отменяет маркировку и обновление настроек. В модели с совместной работой действуют обычные правила Revit по владению элементами.

Механизм хранения: [Autodesk — Extensible Storage](https://help.autodesk.com/cloudhelp/2021/ENU/Revit-API/files/Revit_API_Developers_Guide/Advanced_Topics/Storing_Data_in_the_Revit_model/Revit_API_Revit_API_Developers_Guide_Advanced_Topics_Storing_Data_in_the_Revit_model_Extensible_Storage_html.html).

## Сборка

Из корня репозитория:

```powershell
.\plugins\vernadskogo\scripts\build.ps1
```

Нужны .NET SDK 8, .NET Framework 4.8 targeting pack, API установленного Revit 2024 и Inno Setup 6. Сценарий сначала запускает тесты, затем собирает DLL и установщик. Доступны параметры `-DotNetPath`, `-RevitApiRoot`, `-InnoCompilerPath` и `-SkipInstaller`.

Результаты:

- `dist/vernadskogo/2024/Vernadskogo.App.dll`;
- `dist/vernadskogo/installer/Vernadskogo-Revit2024-Setup.exe`.

Установщик размещает DLL в `%APPDATA%\Vernadskogo\2024`, а собственный манифест — в `%APPDATA%\Autodesk\Revit\Addins\2024\Vernadskogo.addin`. Удаление через список установленных приложений Windows удаляет только этот плагин. DLL Revit API не распространяются.

## Проверка в Revit на копии модели

Модульные тесты покрывают вычисления без запуска Revit. Для проверки параметров и сохранения на настоящей модели предусмотрен интеграционный сценарий:

```powershell
.\plugins\vernadskogo\scripts\test-model.ps1 -ModelPath 'C:\path\project_К1_model.rvt'
```

Он создаёт копию в `tmp/vernadskogo-audit/<идентификатор>/`, запускает отдельный Revit 2024, использует производственный код чтения и записи, проверяет все панели, повторный запуск, смену направления, откат, сохранение и повторное открытие. Сопоставления материалов в этой копии — тестовые. Исходная модель не открывается для записи; её SHA256 проверяется до и после. Отчёт `report.json` и журнал прогресса находятся в папке запуска. Если Revit спрашивает о загрузке неподписанной тестовой надстройки, её нужно разрешить вручную. После проверки удаляется только временный манифест, завершается только запущенный тестовый процесс; уже открытые экземпляры Revit не затрагиваются.

Проверка интерфейса и визуальное сравнение с планом:

1. Проверить наличие команды и список материалов, в том числе один материал в нескольких типах.
2. Назначить номера двух материалов и промаркировать два этажа со смещёнными контурами. Проверить начало с 1 на каждом этаже и общий порядок для разных материалов.
3. Сменить начальное направление, повторить маркировку и сверить с планом в ориентации «Условный север».
4. Сохранить и повторно открыть RVT: номера материалов и направление должны восстановиться.
5. Отменить маркировку через Undo и убедиться, что восстановились прежние значения.
6. На копии модели проверить ошибку имени корпуса/уровня и ошибку записи недоступного параметра: частичной маркировки быть не должно.
