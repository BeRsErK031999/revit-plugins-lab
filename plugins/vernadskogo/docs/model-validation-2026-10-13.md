# Проверка «Вернадского» 1.0.2 на модели проекта

Дата: 13.10.2026. Revit 2024, сборка API/приложения `24.3.50.51`.

## Изменения

- Исправлена запись `GP_Этаж` с типом «Денежная единица»: `StorageType.Double`, спецификация `autodesk.spec.measurable:currency-2.0.0`. Номер этажа записывается числом через `Set(double)`, читается обратно через `AsDouble`. Сам параметр и денежный формат проекта не меняются. Поддержка текста и целого числа сохранена; также поддерживается тип «Число».
- Материал берётся из параметра **типа** «Материал несущих конструкций» (`STRUCTURAL_MATERIAL_PARAM`). Старый «Материал стен» не используется.
- Вкладка **Вернадского**, группа **АР**, команда **Маркировка панелей**.

## Проверенная модель

Исходный файл: `D114_Р_АР_К1_rvt24_отсоединено.rvt`.

SHA256 исходного файла до и после проверки:

```text
381AF18A9AD702F3844846DC9A00BBDA77DFBFF86240882A2435C3660690B436
```

Тест запускался в отдельном экземпляре Revit на копии. Оригинал не открывался для записи. Номера материалов в тестовой копии были условными тестовыми значениями; в рабочей модели их по-прежнему задаёт пользователь.

Обнаружено **428 панелей**, **13 этажей (2–14)**, **3 материала**:

- «Панель волнистая»;
- «Панель  прямая_керамогранит»;
- «Панель прямая».

У всех 428 панелей `GP_Этаж` имеет тип Double / Currency. У элемента **2626276** («1500х2940h») до маркировки числовое значение было 0; после записи — **14**, отображаемое значение в тестовом сеансе — `14.00`.

## Результаты

Все **36 модульных тестов** и **14 проверок внутри Revit** завершились успешно:

1. Зарегистрированы вкладка «Вернадского», группа «АР» и команда маркировки.
2. Найдены панели по заданным критериям типов.
3. Материал каждой панели соответствует «Материалу несущих конструкций» её типа.
4. Все секции, этажи и полные марки записаны и прочитаны обратно; марки уникальны, номера на каждом этаже идут непрерывно от 1.
5. Повторная запись тех же значений не вызывает ошибок.
6. Смена начального направления с юга на северо-восток меняет нумерацию и корректно перезаписывает все панели.
7. Направление сохраняется в модели.
8. Все соответствия материалов сохраняются в модели.
9. Новые общие и проектные параметры не создаются.
10. Откат группы транзакций восстанавливает исходные значения всех панелей.
11. Откат восстанавливает прежние настройки.
12. После сохранения и повторного открытия RVT все записанные значения панелей сохраняются.
13. После повторного открытия сохраняются соответствия материалов и направление.
14. После повторного открытия находятся все 428 панелей.

Сборка DLL и отдельного установщика версии **1.0.2** завершилась без ошибок; компиляция C# — без предупреждений. Проверка параметров выполнялась производственным кодом, подключённым к тестовой надстройке. Она не подменяла Revit API имитациями. Визуальный обход каждой панели на фасадах вручную не проводился; направление и расчёт порядка покрыты модульными тестами.
