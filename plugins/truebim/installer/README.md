# Установщик TrueBIM

Установочный пакет TrueBIM собирается с помощью Inno Setup.

Версия **0.2.39** исправляет сообщения о ручной принадлежности отделки:
показывает ненайденный номер помещения и ID исключённых элементов вместо
общего геометрического замечания. Методичка объясняет перенос и перенумерацию.
Проверка на копии модели в Revit 2023: [отчёт](../docs/finish-schedule-manual-ownership-2026-10-21.md).
Включены изменения заполнятора арматуры из версии 0.2.38.

Версия **0.2.38** добавляет в заполнятор арматуры галочки отдельных стержней,
фильтр по семейству и типу и сортировку таблицы. Заполняются только отмеченные
строки текущего фильтра. Например, прямые стержни и хомуты одного каркаса
можно обработать отдельно. Выбор сохраняется при смене параметра и фильтра.

Версия **0.2.37** добавляет **КР → Заполнятор арматуры**: выбранный параметр
экземпляра, подтверждение перезаписи или заполнение только пустых значений,
сохранение вложенности и системы армирования. В пакет включён Revit 2019.
Проверки и ограничения: [отчёт](../docs/rebar-fill-validation.md).
Для API отсутствующих установленных версий сборщик принимает
`-RevitApiRoots @{ '2019' = 'C:\References\Revit2019' }`; DLL API в поставку не входят.

Версия **0.2.36** дополняет встроенную методичку «Ведомости отделки»:
зачем нужна галочка «Записывать фактическую принадлежность в элементы отделки»,
когда её включать и как пересчитывать площади после ручных исправлений.
Добавлены пошаговая инструкция, пример переноса из помещения 210 в 211
и пояснения к предупреждениям о принадлежности. Логика расчёта не менялась.

Версия **0.2.35** — общий выпуск из `main` для **Revit 2021–2026**.
Он включает последние изменения ведомости отделки, ТЭП, разбиения арматуры,
обновления электрических схем, экспорта целых листов DWG и удаления фильтров.
Состав и границы проверки: [отчёт выпуска](../docs/consolidated-release-2026-10-21.md).
Плагин «Вернадского» выпускается отдельным установщиком в соответствии с его назначением.

Версия **0.2.34** меняет расчёт «Ведомости отделки»: включённая галка записи
принадлежности выполняет автоматическое назначение, выключенная сохраняет
ручные назначения и пропускает геометрический поиск. Ведомость в обоих режимах
рассчитывается по параметрам принадлежности элементов.

Версия **0.2.33** включает команду **TrueBIM → АР → Проверка ТЭП** в общей
сборке `TrueBIM.App.dll`; отдельная установка ZIP-пакета ТЭП не требуется.
Инструкция поставляется в `Docs/tep-check.md`. Расчёт на реальных моделях
проверен в Revit 2024.3.5; остальные включённые версии проходят проверку сборки.
Помещения с нулевой площадью пропускаются с диагностикой; затронутые результаты
и итоги помечаются `*`, а в Excel дополнительно выделяются жёлтым.

Основной файл установщика:

```text
plugins/truebim/installer/TrueBIM.iss
```

Чтобы собрать плагин для всех поддерживаемых версий Revit и создать установщик, выполните команду из корня репозитория:

```powershell
.\plugins\truebim\scripts\build-installer.ps1
```

Если на компьютере установлены не все поддерживаемые версии Revit, можно собрать пакет только для доступных версий:

```powershell
.\plugins\truebim\scripts\build-installer.ps1 -AllowMissingRevitApi
```

Готовые файлы появятся здесь:

```text
dist/revit/<версия Revit>
dist/installer/TrueBIM-Setup.exe
```

При сборке очищается только `dist/revit`, поэтому отчёты ТЭП, отдельные пакеты
и сохранённые версии установщика в других подкаталогах `dist` остаются на месте.

Установщик работает для текущего пользователя и не требует прав администратора. Файлы размещаются по адресам:

```text
%APPDATA%\TrueBIM\<версия Revit>\
%APPDATA%\Autodesk\Revit\Addins\<версия Revit>\TrueBIM.addin
```

Установщик спрашивает, для каких версий Revit установить TrueBIM. По умолчанию отмечены все версии, включённые в пакет; ненужные можно снять. Для каждой выбранной версии записываются собственная сборка и манифест надстройки, даже если этот Revit будет установлен позже. Версии, исключённые при сборке через `-AllowMissingRevitApi`, не показываются. При повторном запуске по умолчанию снова выбраны все версии.

Отладочные файлы в готовый пакет не включаются. Один установщик может содержать сборки для Revit 2019–2026; одинаковые файлы сжимаются вместе, поэтому размер пакета остаётся умеренным.

На рабочем компьютере путь к программе сборки можно указать параметром `-InnoCompilerPath`. Если Inno Setup установлен в обычную папку, сценарий найдёт его автоматически.
