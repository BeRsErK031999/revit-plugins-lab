# Обновление электрической схемы

В Revit 2023: **TrueBIM → ЭОМ → Обновить схему**. Векторная иконка изображает шину с отходящими линиями. Модальное окно содержит предпросмотр, выбор групп, диагностику и отдельную прокручиваемую методичку.

Выделенные в Revit основные элементы схемы автоматически отмечаются в таблице. Дополнительно можно отметить строки в окне; без выделения ни одна строка не отмечается автоматически. Все схемы проекта показаны с видом и ID. Кнопка записи обрабатывает только отмеченные строки. Предпросмотр не меняет документ.

## Контракт

Источники — верхнеуровневые модельные `FamilyInstance` активного документа с общими параметрами согласованного контракта. Связи, элементы узлов и вложенные экземпляры исключаются. Стадии и варианты отдельно не фильтруются. Самостоятельные нагрузки только во вложенных семействах этим режимом не поддерживаются.

Цель — верхнеуровневые элементы узлов с GUID установленной мощности схемы. Параметры экземпляра определяются по GUID, текстовый параметр схемы `• Потребитель` — по точному уникальному имени. Подробности и GUID: [проверка модели](electrical-schematic-sync-model-validation-2026-09-29.md).

Планировщик нормализует префикс `Гр.`, регистр, крайние пробелы и латинскую c / кириллическую с только для сопоставления. Суммирует каждый уникальный ID источника; повторяющиеся названия объединяет и сортирует. Сумма в ваттах делится на 1000, результат записывается в ВА по соглашению семейства. Формулы и коэффициенты семейства не меняются.

Пустая группа, дубликаты основных схем во всём документе, отсутствие источников, неверные/недоступные параметры, отрицательная или нечисловая мощность блокируют соответствующую группу. Числовой ноль допустим; незаполненный существующий числовой параметр считается нулём. Отсутствующий параметр не подменяется нулём. Пустые названия не включаются в список, с предупреждением. Если все названия пустые, поле схемы очищается.

Перед записью сервис повторно читает модель и отклоняет изменившиеся строки. Два параметра одной группы записываются в одной транзакции с проверкой прочитанного результата. Любое сообщение Revit о сбое транзакции приводит к откату группы; общий TransactionGroup объединяет успешные записи в одну операцию отмены.
