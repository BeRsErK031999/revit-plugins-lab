# ИОС · Обозначение системы

В проекте Revit откройте **TrueBIM → Инструменты → Разделы → ИОС · Обозначение системы**. Команда записывает результат в общий текстовый параметр экземпляра `• Обозначение системы`.

| Режим | Какие экземпляры получат значение |
| --- | --- |
| Выделенные элементы | Выбранные экземпляры, их общие вложенные семейства на всех уровнях, изоляция и внутренняя изоляция воздуховодов. Можно выбрать отдельно вложенный экземпляр или изоляцию. |
| Элементы на активном виде | Элементы активного документа, отображаемые на виде с его текущими настройками, в том числе с временным скрытием или изоляцией. Видимый вложенный экземпляр может прочитать значение скрытого родителя. |
| Все элементы проекта | Экземпляры вентиляции и трубопроводных систем в активном документе, включая их изоляцию и доступные в проекте вложенные экземпляры. |

Для изоляции источником служит её собственное «Сокращение системы». Для оборудования и семейств с соединителями команда читает сокращения типов назначенных систем ОВ и ВК. Вложенные экземпляры наследуют вычисленное значение родительского семейства, в том числе при выборе одного вложенного экземпляра. Вложенные детали, которые являются только геометрией семейства, собственной строки параметров в проекте не имеют.

Две системы с сокращениями `В1` и `П1` дают `В1, П1`. Две системы с сокращением `В1` дают `В1`. Пустой результат очищает прежнее обозначение. Совпадающие значения пропускаются.

Если для записи недоступен общий параметр, появится предупреждение. **Отменить выполнение** завершает команду до изменения модели. **Продолжить** обновляет доступные элементы. Отчёт показывает количество обновлённых, очищенных и пропущенных экземпляров. В подробностях перечислены ID пропусков и причины. Запись можно отменить одним действием Revit.

## Проверка на копии проекта

1. Выберите изолированный участок и оборудование с общими вложенными деталями. Проверьте изоляцию, вложенные детали и соседний экземпляр за пределами выделения. Затем выберите только вложенную деталь и проверьте, что родитель сохранил исходное обозначение.
2. Проверьте оборудование с разными и одинаковыми сокращениями двух систем, элемент с пустым сокращением и ранее заполненным обозначением. Повторите команду и проверьте количество совпадений.
3. Временно изолируйте один элемент на виде. Обновите вид и проверьте прежние значения скрытых элементов. Повторите с временным скрытием, обрезкой вида и скрытой категорией изоляции.
4. При отсутствии общего параметра проверьте оба варианта предупреждения. Сверьте пропуски по ID, затем выполните отмену записи в Revit.

## Результаты проверки в Revit 2024.3

Проверка выполнена 24 ноября 2026 на отсоединённой копии проекта вентиляции и трубопроводов. Из 19 188 экземпляров при полном прогоне обновлены 18 988 значений, очищены 15, ещё 185 уже совпадали. Повторный расчёт подтвердил совпадение всех 19 188 значений.

В проекте проверены изоляция с собственным сокращением, вложенный экземпляр при выборе только родителя и только потомка, оборудование с двумя одинаковыми и двумя разными сокращениями. На поэтажном плане проверены обрезка и временная изоляция, на 3D-виде — временное скрытие и изоляция. Электротехнический трубопровод (Conduit) исключён из выделения.

После исключения категории из привязки общего параметра расчёт пропустил 1 839 экземпляров этой категории. При вызове команды с ленты на выделении из двух элементов проверены отмена до записи, продолжение с пропуском, итоговый отчёт и восстановление исходного значения одним Undo. В том же меню открыта соседняя команда расчёта потери напряжения.
