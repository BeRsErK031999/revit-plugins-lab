Нативный сценарий кнопки проверен в Revit 2024.3. Для остальных годов подтверждены компиляция и состав пакета; запуск кнопки в этих версиях не выполнялся. Установка проверена в существующем профиле Windows, не на чистой машине. Цифровой подписи издателя нет. Разрыв SMB во время физической передачи не моделировался: обработка тайм-аута проверена программно, недоступный путь — в нативном окне. У сотрудников до 0.2.52 кнопки ещё нет: первый переход выполняется обычным установщиком.
