# Проверка снятия ограничения количества значений — 2026-10-21

В «Цветах по параметрам» удалено ограничение в 40 уникальных значений.
Предупреждение о возможном замедлении при применении более 25 фильтров сохранено.

## Установка

- Собраны DLL для Revit 2021–2026 с соответствующими версиями Revit API.
- Обновлены установленные `%APPDATA%\TrueBIM\<год>\TrueBIM.App.dll`.
- SHA-256 каждой установленной DLL совпадает с соответствующей сборкой.
- Исходные DLL и манифесты сохранены в резервной копии. Манифесты установки не менялись.
- Это локальное обновление установленного плагина; новый установщик и публикация релиза не выполнялись.

## Проверка в Revit

Проверка выполнена через настоящий интерфейс установленного плагина в Revit
2021.1.10. Использована отсоединённая копия
`KRRT-GPP-35bis_RD_061_KM1_AR21.rvt`, открытая в режиме просмотра; изменения не сохранялись.

| Проверка | Результат |
| --- | --- |
| Параметр | `ADSK_Марка`, проектный, экземпляр, текст |
| Количество уникальных значений в интерфейсе | 41 |
| Конец списка | Доступно последнее значение `ОП2с` |
| Предупреждение | Показано до применения; сообщает о 41 фильтре и возможном замедлении вида |
| Первое применение | Создано 41, применено к активному виду 41, пропущено значений 0 |
| Повторное применение | Обновлено 41, применено 41, пропущено значений 0 |
| Независимый список управления фильтрами | После обновления показывает 41 фильтр `BIM_F_` |
| Фильтр последнего значения | `BIM_F_ADSK_Марка_ОП2с_63ECDC77`, правило `ADSK_Марка = «ОП2с»` |

Применение выполнено во временном режиме. Параметр неприменим к двум выбранным
категориям; плагин сообщил об их исключении. Рабочие фильтры относятся к несущему
каркасу, несущим колоннам и обобщённым моделям.

активный вид (`Setting active view is temporarily disabled`). Дальнейшая проверка
выполнена вручную через UI; автоматическая проверка совпадения правил со всеми

рядом с локальными материалами, а его временный манифест удалён.

обновления формата; результат проверки относится к Revit 2021. Другие версии
проверены сборкой и сверкой установки, без выполнения этого сценария в UI.
