# Ведомость отделки: пустая строка перед данными

## Изменение 0.2.20

Новый выпуск однократно получает внешний вид из шаблона спецификации помещений
**«TrueBIM • Отделка • Без пустой строки»**, подготовленного в текущем проекте.
После переноса плагин создаёт свои поля, фильтры, сортировку, шапку и служебные
параметры выпуска. Связь строк с помещениями сохраняется.

Первичная настройка шаблона обязательна. Если его нет, предварительный план
останавливает формирование и показывает инструкцию до записи параметров.
Имя шаблона само по себе не отключает разделительную строку: галочку необходимо
снять в его настройках, как описано ниже. Готовый RVT-шаблон в пакет не включён.

## Настройка проекта один раз

1. Откройте обычную спецификацию категории «Помещения».
2. В свойствах откройте **Вид → Изменить**. Снимите **Отделять данные пустой строкой** и нажмите **ОК**.
3. Создайте из этого вида шаблон с точным именем **TrueBIM • Отделка • Без пустой строки**.
4. В настройках шаблона убедитесь, что та же галочка снята.
5. Повторите формирование в TrueBIM. Этот шаблон будет использоваться и для следующих выпусков.

Шаблон хранится в проекте. Его можно включить в проектный RTE или перенести в
другой проект штатными средствами Revit. Уже выпущенные ведомости плагин не
переформатирует; при необходимости снимите галочку у них вручную.

## Реализация

- `FinishScheduleAppearanceTemplateService` находит шаблон по имени и категории.
- Перед применением через `ElementTransformUtils.CopyElements` создаётся временная копия. В ней включён только
  `SCHEDULE_SHEET_APPEARANCE_PARAM`; остальные разделы исключаются.
- `ApplyViewTemplateParameters` переносит оформление однократно. Новый выпуск
  не остаётся связанным с шаблоном, исходный шаблон не редактируется.
- Временная копия удаляется в той же транзакции. При ошибке действует общий откат
  формирования ведомости и записи параметров.
- Наличие шаблона проверяется до записи. Отдельного публичного свойства для
  проверки состояния нужной галочки нет; плагин использует сохранённое оформление.

`ScheduleSortGroupField.ShowBlankLine` управляет строками между группами и не
заменяет эту настройку. В плагине он по-прежнему выключен.

## Статус проверки

По указанию пользователя функциональная проверка в Revit и установка новой
версии не выполняются. Результаты проверок 0.2.19 из соседнего отчёта не являются
проверкой этого изменения. Для 0.2.20 выполняется только сборка установщика.
