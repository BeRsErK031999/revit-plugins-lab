# Ведомость спецификаций

Инструмент расположен на вкладке `TrueBIM`, панель `Оформление`:

- `Ведомость спецификаций` — формирование новой таблицы по выбранным листам;
- `Настройки ведомости` — фильтр и источник восстановления шаблона.

## Рабочий сценарий

1. Выберите один или несколько листов в диспетчере проекта Revit.
2. При необходимости настройте исключающий фильтр.
3. Нажмите `Ведомость спецификаций`.
4. TrueBIM найдёт все размещённые на выбранных листах спецификации, кроме ревизий основной надписи и ранее созданных ведомостей.
5. Для каждой спецификации название читается из первой строки её шапки. Имя вида в диспетчере проекта в таблицу не записывается.
6. Создаётся новая копия `• Т • Общие данные • Ведомость спецификаций` с первым свободным именем `(2)`, `(3)` и так далее.

Ранее созданные ведомости не перезаписываются.

## Сегменты и дубликаты

- разные сегменты одного `ViewSchedule` объединяются в одну строку;
- номера листов перечисляются через запятую в естественном порядке;
- повторное размещение одного сегмента на разных листах не блокирует результат, но попадает в предупреждение;
- разные спецификации с одинаковой первой строкой шапки остаются отдельными строками и попадают в предупреждение с именами видов и листами.

## Фильтр

Фильтр выключен по умолчанию. В настройках можно указать:

- имя параметра спецификации;
- текст, наличие которого исключает спецификацию.

Сравнение выполняется без учёта регистра по правилу `содержит`. Если параметр отсутствует, спецификация включается, а команда показывает предупреждение. Пустое значение также не исключает спецификацию.

Настройки сохраняются отдельно для каждой основной версии Revit.

## Контроль шаблона

Исправный шаблон должен:

- называться `• Т • Общие данные • Ведомость спецификаций`;
- содержать в первой строке заголовок `Ведомость спецификаций`;
- содержать строку `Лист | Наименование | Примечание`;
- иметь не менее одной пустой строки после названий столбцов;
- не быть размещённым на листе.

Если шаблон отсутствует или повреждён, команда предлагает восстановить его из указанного в настройках `.rte` или `.rvt`. Сначала проверяется эталонная таблица. Только после успешной проверки текущий повреждённый шаблон удаляется и копируется исправный. Операция выполняется одной транзакцией Revit.

## Ручная проверка

1. Запуск без выбранных листов показывает понятную ошибку и не меняет проект.
2. Выбор нескольких листов создаёт ведомость с заголовком и тремя исходными колонками.
3. Названия строк совпадают с первой строкой шапки исходных спецификаций.
4. Повторный запуск создаёт следующее свободное имя и не изменяет предыдущую ведомость.
5. Включённый фильтр исключает только спецификации с настроенным значением.
6. Разбитая спецификация на нескольких листах формирует одну строку с объединёнными номерами.
7. Дубликаты размещений и одинаковые заголовки не прерывают выполнение и перечисляются в подробностях итогового окна.
8. Повреждённый шаблон без настроенного эталона не удаляется.
9. Восстановление из несовместимого или повреждённого файла завершается откатом.
