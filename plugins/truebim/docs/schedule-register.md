# Ведомость спецификаций

Инструмент расположен на вкладке `TrueBIM`, панель `Оформление`:

- `Ведомость спецификаций` — формирование новой таблицы по выбранным листам;
- `Настройки ведомости` — фильтр и источник восстановления шаблона.

## Рабочий сценарий

1. В диспетчере проекта выделите один или несколько листов. Без выбранных листов команда покажет ошибку и не откроет рабочее окно.
2. Нажмите `Ведомость спецификаций`.
3. В открывшемся окне проверьте read-only список выбранных листов. Чтобы изменить набор, закройте окно и повторите выбор в диспетчере проекта.
4. При необходимости нажмите компактный значок готовности рядом с поиском: он раскрывает состояние шаблона и фильтра.
5. При необходимости откройте `Настройки` или встроенную `Методичку`, затем нажмите `Создать ведомость`.
6. TrueBIM найдёт все размещённые на выбранных листах спецификации, кроме ревизий основной надписи и ранее созданных ведомостей.
7. Для каждой спецификации название читается из первой строки её шапки. Имя вида в диспетчере проекта в таблицу не записывается.
8. Создаётся новая копия `• Т • Общие данные • Ведомость спецификаций` с первым свободным именем `(2)`, `(3)` и так далее.

Ранее созданные ведомости не перезаписываются.

## Сегменты и дубликаты

- разные сегменты одного `ViewSchedule` объединяются в одну строку;
- номера листов перечисляются через запятую в естественном порядке;
- повторное размещение одного сегмента на разных листах не блокирует результат, но попадает в предупреждение;
- разные спецификации с одинаковой первой строкой шапки остаются отдельными строками и попадают в предупреждение с именами видов и листами.

## Фильтр

Фильтр выключен по умолчанию. В настройках можно указать:

- имя параметра спецификации;
- текст, наличие которого исключает спецификацию.

Сравнение выполняется без учёта регистра по правилу `содержит`. Если параметр отсутствует, спецификация включается, а команда показывает предупреждение. Пустое значение также не исключает спецификацию.

Настройки сохраняются отдельно для каждой основной версии Revit.

## Контроль шаблона

Исправный шаблон должен:

- называться `• Т • Общие данные • Ведомость спецификаций`;
- содержать в первой строке заголовок `Ведомость спецификаций`;
- содержать строку `Лист | Наименование | Примечание`;
- иметь не менее одной пустой строки после названий столбцов;
- не быть размещённым на листе.

Если шаблон отсутствует или повреждён, команда предлагает восстановить его из указанного в настройках `.rte` или `.rvt`. Сначала проверяется эталонная таблица. Только после успешной проверки текущий повреждённый шаблон удаляется и копируется исправный. Операция выполняется одной транзакцией Revit.

Если заголовок и колонки исправны, но кто-то заполнил пустые строки шаблона или разместил его на листе, внешний файл не требуется. При запуске TrueBIM автоматически создаёт чистую копию с прежним оформлением, удаляет испорченный оригинал и продолжает формирование ведомости. Внешний `.rte/.rvt` нужен только при повреждении структуры или полном отсутствии подходящего шаблона.

## Ручная проверка

1. Запуск без предварительного выбора листов показывает ошибку и не открывает рабочее окно.
2. В окне отображаются только листы, выбранные в диспетчере проекта до запуска команды.
3. Список листов доступен только для чтения, поиск фильтрует строки, а значок готовности раскрывает и сворачивает состояние шаблона и фильтра.
4. Выбор нескольких листов создаёт ведомость с заголовком и тремя исходными колонками.
5. Названия строк совпадают с первой строкой шапки исходных спецификаций.
6. Повторный запуск создаёт следующее свободное имя и не изменяет предыдущую ведомость.
7. Включённый фильтр исключает только спецификации с настроенным значением.
8. Разбитая спецификация на нескольких листах формирует одну строку с объединёнными номерами.
9. Дубликаты размещений и одинаковые заголовки не прерывают выполнение и перечисляются в подробностях итогового окна.
10. Шаблон с заполненными рабочими строками автоматически очищается без выбора внешнего файла.
11. Повреждённая структура шаблона без настроенного эталона блокирует кнопку запуска и не меняет проект.
12. Восстановление из несовместимого или повреждённого файла завершается откатом.
