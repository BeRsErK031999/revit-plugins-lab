# Рамка выбора

TrueBIM 0.2.43, панель **Виды**, кнопка **Рамка выбора**.

Сначала выберите один или несколько элементов, затем нажмите кнопку. Для элемента
в RVT-связи наведите курсор и нажимайте Tab до подсветки нужного элемента. Для
множественного выбора используйте Ctrl. Разрешён смешанный выбор элементов
основного проекта и нескольких экземпляров RVT-связей.

Команда читает предварительный выбор через `Selection.GetReferences()` и работает
в Revit 2023–2026. В 2019–2022 эта команда показывает сообщение об ограничении API
и ничего не изменяет. Дополнительный выбор после запуска не предлагается.
Обычный штатный инструмент Revit остаётся доступен для собственных элементов.

## Выбор 3D-вида

1. Если активен 3D-вид, ограничивается он.
2. Иначе используется последний посещённый из ещё открытых 3D-видов. Если история
   посещений отсутствует, выбирается первый открытый 3D-вид из списка Revit.
3. Если открытых 3D-видов нет, открывается существующий `{3D}` для обычного проекта
   или `{3D - имя пользователя Revit}` для совместного проекта.
4. Если соответствующего вида нет, плагин запускает штатную команду Revit
   «3D-вид по умолчанию». Revit сам создаёт стандартный или пользовательский вид
   со своими настройками. Затем плагин автоматически применяет рамку по выбору,
   зафиксированному при нажатии кнопки. Повторно выбирать элементы не нужно.

Команда доступна независимо от исходного типа вида. Выбранные объекты должны иметь
габариты геометрии модели; аннотации и виды не являются подходящими объектами.

## Границы и настройки

Для каждого элемента берутся габариты полной модели, а для элемента связи также
учитывается трансформация конкретного экземпляра связи. Преобразуются все восемь
углов габарита: это важно для повернутых и зеркальных связей. Общая рамка имеет
фиксированный отступ **300 мм по каждой из шести граней**. Это согласованная
замена штатного отступа, формула которого не предоставлена используемым API.

Ориентация рамки существующего вида сохраняется. Команда включает рамку, меняет
её границы и открывает целевой вид. Она не меняет шаблон, стиль, детализацию,
фазу, ориентацию камеры, фильтры и видимость категорий, не скрывает и не изолирует
элементы. Поэтому объекты, скрытые настройками целевого вида, могут остаться
невидимыми. Содержимое связанных файлов не редактируется.

Если выделена связь целиком, её габарит будет использован целиком. Для ограничения
по отдельному элементу нужно выбрать именно элемент внутри связи. Выбор вложенной
связи через элемент другой связи пока отклоняется с пояснением.

Пустой выбор, объекты без габаритов и недоступные связи приводят к сообщению без
изменений. Смешанный выбор с неподходящим объектом отклоняется целиком, чтобы не
создать рамку по неполному набору. Ошибка изменения или открытия вида откатывает
транзакции изменения рамки. Создание отсутствующего стандартного вида выполняет
отдельная штатная команда Revit: если последующее ограничение не удалось,
созданный вид остаётся доступен; его создание можно отменить обычной отменой.
Ограничения шаблона и совместного редактирования не снимаются.

## Проверка

Результат выпуска 0.2.43: [проверки от 2026-10-29](selection-box-validation-2026-10-29.md).

Нативный сценарий: `scripts/test-selection-box-2024.ps1`. Он копирует RVT из
указанного каталога в отдельную папку `tmp`, запускает Revit 2024 Viewer и
проверяет смешанный выбор, геометрию рамки, повёрнутые/зеркальные связи и обычные/
пользовательские виды. Исходные файлы проверяются по SHA-256 до и после запуска;
изменения тестовых документов не сохраняются. Итоговый статус определяется файлом
`done`; файл `failed` или незавершённый запуск не считаются успешной проверкой.

API: [изменения Selection в Revit 2023](https://blog.autodesk.io/whats-new-in-the-revit-2023-api/).
