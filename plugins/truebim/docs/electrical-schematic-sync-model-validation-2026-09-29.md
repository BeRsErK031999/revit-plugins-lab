Символ `•` действительно входит в имена параметров. Он не является только обозначением в интерфейсе. Нельзя искать параметры по сокращённым именам со скриншотов. Для общих параметров использовать GUID. Для `• Потребитель` схемы искать точное имя в проверенном семействе и требовать ровно один текстовый параметр экземпляра с возможностью записи. Не использовать GUID исходного потребителя для поля назначения: определения различаются.

Установленная мощность у самих розеток равна нулю и не является источником суммы. Одноимённые параметры `• Расчетная мощность` на плане и схеме также различаются по GUID и типу данных. Это не один общий параметр.

Правило численного переноса, подтверждённое пользователем и примером:

```text
sumWatts = сумма UnitUtils.ConvertFromInternalUnits(sourcePower.AsDouble(), UnitTypeId.Watts)
schemeValueVA = sumWatts / 1000
targetPower.Set(UnitUtils.ConvertToInternalUnits(schemeValueVA, UnitTypeId.VoltAmperes))
```

Для данного семейства это условное представление киловатт в поле с единицами В·А, а не физическое преобразование активной мощности в полную. Плагин реализует именно согласованное соглашение. Коэффициенты в сумме не применяются, дополнительное умножение на количество устройств не выполняется.

В семействе схемы есть формулы:

```text
• Расчетная мощность = • Установленная мощность * • Кс / 1 Вт
• Кс = • Коэффициент спроса
```

Ток вычисляется из `• Расчетная мощность`, напряжения и коэффициента мощности; внутри формулы присутствует множитель `1000 Вт`. В примере Кс = 1, напряжение = 220 В, коэффициент мощности = 0,96. При мощности схемы 3 В·А расчётное число равно 3, ток — 14,204545… А. Плагин должен записывать установленную мощность и текст потребителей; текущие формулы и коэффициенты семейства остаются под управлением самого семейства. На других экземплярах с Кс, отличным от единицы, зависимое расчётное число закономерно будет отличаться от простой суммы.

Особенности вложенности, обнаруженные в примере:

- В модели семь `FamilyInstance`: две розетки, два вложенных подрозетника, один основной элемент схемы и два вложенных обозначения прокладки.
- Подрозетники `599576` и `602087` имеют пустые группу и наименование, мощность 0, параметры в проекте доступны только для чтения. Они являются компонентами розеток, а не самостоятельными потребителями. Их нельзя включать в число нагрузок или выдавать по ним ложные ошибки «не заполнена группа».
- Элементы `588398` и `588469` вложены в основной элемент схемы `588397` и тоже содержат группу `1.4с`. Это обозначения гофры и скрытой прокладки, а не две дополнительные схемы той же группы. Проверять дубликаты по всем элементам категории без учёта вложенности нельзя.
- Для первой реализации на этих семействах источники и схемы следует отбирать среди верхнеуровневых экземпляров с подтверждённым контрактом параметров. Если позже появятся блоки с самостоятельными нагрузками внутри, для них потребуется отдельное правило учёта, проверенное на образце.
