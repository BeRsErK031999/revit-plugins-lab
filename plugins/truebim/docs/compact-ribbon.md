# Компактная лента TrueBIM

С версии 0.2.40 на вкладке TrueBIM используются четыре панели.

| Панель | Команды |
| --- | --- |
| Быстрый доступ | Цвета по параметрам, Копирование параметров, Печать |
| Виды | Видимость, Оси 2D/3D, Фасады проёмов |
| Инструменты | Выпадающие меню «Модель», «Параметры», «Документы», «Разделы» |
| Помощь | Логи |

В «Быстром доступе» и «Видах» кнопки расположены в три строки. Быстрый доступ
содержит фиксированный набор команд, которые также доступны в тематических меню.

## Содержание меню

- **Модель**: Диспетчер семейств, Замена семейств, Соединить / Вырезать;
  Цвета по параметрам, Проверка параметров, Отчёт коллизий.
- **Параметры**: Копирование параметров, ParaManager, Общие параметры; Рабочие наборы.
- **Документы**: Нумератор листов, Печать; Импорт таблиц, Ведомость спецификаций.
- **Разделы**: АР — Ведомость отделки, Проверка ТЭП; КР — Армирование по изополям,
  Перемычки, Разбить арматуру, Заполнятор арматуры, Свернуть ВРС;
  ЭОМ — Расчет потери напряжения, Обновить схему.

Меню «Видимость» содержит прежний список категорий и показывает их состояние.
«Фасады проёмов» содержит создание фасадов, оформление активного фасада и методичку.
Ограничения доступности команд по текущему виду сохранены.

Старые инструкции с путями «АР», «КР» или «ЭОМ» относятся к соответствующим
группам в **Инструменты → Разделы**. Команды из прежних панелей оформления,
координации, библиотеки, геометрии, проверки модели и администрирования
распределены по меню выше.
