# Общий выпуск TrueBIM 0.2.45 — 30.10.2026

Единый установщик для **Revit 2019–2026** объединяет завершённые изменения
основного репозитория и ветки `codex/vertical-rebar-detailing`. Пользователь
подтвердил завершение печати через встроенный экспорт Revit и разрешил
объединение, push и обновление установщика. PDF24 для этого выпуска не требуется.

## Состав

| Команда | Изменения |
| --- | --- |
| Оформление вертикальных сечений | «Дополнение 3»: три варианта, нативные формулы равенства, разделение цепочек по шагу/форме, отступы 8/16/24 мм, обрывы и редактируемые выноски, количество нерегулярных групп. Горизонтальные виды исключены. |
| Печать и экспорт | Флажки целых групп с частичным состоянием, настройки принтера и экспорта внутри плагина, маски имён. Исправлены путь с `/`, двойное `.pdf` и перекрытый итоговый диалог. Существующий PDF заменяется после успешного создания нового файла. |
| Рамка выбора | Габариты выбранных элементов основной модели и RVT-связей, смешанный выбор, отступ 300 мм, сохранение вида. Предварительный выбор связей поддерживается с Revit 2023. |
| Разбить арматуру | Явные варианты обработки групп и закреплений, сохранение параметров и поддерживаемых аннотаций, откат и безопасный пропуск при изменении соседних элементов. |
| Лента и окраска | Компактная лента со всеми командами, кнопка рамки выбора, отсутствие прежнего лимита значений при окраске по параметру. |

Остальные команды TrueBIM сохранены. Три каталога модулей `Print`,
`SheetNumbering` и `ScheduleColumnCollapse`, иконки и инструкции входят
в каждый годовой комплект. «Вернадского» остаётся отдельным продуктом;
его исходники этим выпуском не меняются.

## Поставка и границы

Один файл `TrueBIM-Setup-0.2.45.exe` содержит все восемь версий. При запуске
можно выбрать нужные годы Revit. Установка выполняется для текущего пользователя
в `%APPDATA%\TrueBIM`; права администратора не требуются. Перед установкой
следует закрыть Revit. Подробности: [инструкция установщика](../installer/README.md).

Встроенный экспорт PDF доступен с Revit 2022. Физическая печать, PDF24,
пакет 95+ листов и нативный запуск новых изменений во всех восьми версиях
не входят в подтверждённую проверку этого выпуска. Установщик собирается
и проверяется как артефакт; установка на рабочий компьютер отдельно не выполнялась.

Исходные RVT, ручные эталоны, предыдущие версии пакета и результаты проверок
сохранены. DLL, PDF, модели, логи, TRX и установщики не добавляются в Git.
