# Геометрическая отделка помещений · 0.2.50

В `TrueBIM → Инструменты → Разделы → АР` добавлены три самостоятельные команды: **Отделка полов**, **Отделка стен**, **Отделка потолков**. Они создают обычные элементы Revit по помещениям. Существующая команда «Ведомость отделки» работает отдельно.

## Как создать отделку

1. Откройте проект. При необходимости заранее выделите помещения: окно автоматически выберет эту область.
2. Откройте нужную команду. Выберите весь проект, активный вид, выделенные помещения или этаж. Фильтр ищет часть имени, номера или назначения помещения. Кнопка «Показать помещения» обновляет таблицу; она не создаёт элементы.
3. Ограничьте список существующих типов максимальной толщиной и/или значением параметра типа. Новые типы плагин не создаёт. Для стен доступны обычные типы стен.
4. Назначьте тип в каждой строке либо используйте «Назначить всем строкам». Снимите галочки со строк, которые создавать не нужно. Для стен доступны группировки по типу основы, имени помещения или сочетанию имени и типа основы. Для полов и потолков строки объединяются по имени помещения.
5. Задайте отметку и признак «Граница помещения». По умолчанию созданная отделка не ограничивает помещения. Признак задаётся отдельно для каждой строки.
6. При необходимости выберите параметр помещения и параметр экземпляра отделки. Например: «Номер» → «Комментарии». Оба пустых поля отключают перенос. Текстовые значения и совместимые числовые параметры переносятся без поиска по одному только имени. Если параметр недоступен, изменения этого помещения откатываются, причина попадает в замечания.
7. Нажмите «Проверить», затем «Создать». Итог содержит число созданных элементов, обработанных и пропущенных помещений. Выбранное замечание можно использовать для перехода к помещению в Revit.

Настройки сохраняются отдельно для проекта и команды в `%APPDATA%\TrueBIM\GeometricFinishes`. Кнопка «Сохранить настройки» сохраняет назначения без создания элементов. Во время обработки «Закрыть» меняется на «Остановить»: остановка отменяет весь текущий запуск. Успешный запуск можно отменить одной командой Undo в Revit.

## Геометрия и отметки

| Команда | Поведение |
|---|---|
| Полы | Горизонтальное перекрытие по чистовой границе помещения, с внутренними отверстиями. В дверях используется та же граница помещения. Отметка от уровня задаёт **верх** пола; «Положить на перекрытие» размещает низ отделки на верхней грани основы. |
| Стены | Отделочная стена с внутренней стороны границы, от низа до верха помещения. Смещение снизу меняет нижнюю отметку; верх остаётся на верхней границе. Реальные вырезы дверей и окон переносятся в отделку. Соединение с основной стеной можно отключить; стены из связей не соединяются с элементами основного файла. |
| Потолки | Горизонтальный системный потолок либо перекрытие. Отметка от уровня задаёт **низ** потолка. «Прижать к перекрытию» размещает верх отделки на нижней грани основы с учётом толщины типа. |

Для пола и потолка также доступна нижняя/верхняя граница помещения. В автоматических режимах поле смещения от уровня отключено. Поиск перекрытия учитывает текущий файл и загруженные связи, проверяет вертикаль через точку помещения и ближайшую подходящую горизонтальную грань в пределах 3 м от соответствующей границы. Для потолка учитывается нижняя грань верхнего перекрытия, в том числе находящаяся ниже верхней границы помещения.

Помещения берутся только из текущего файла. Ограничивающие стены могут быть в нём или в загруженной RVT-связи с включённым признаком границы помещения. Трансформация связи учитывается. Созданные элементы всегда принадлежат текущему файлу. Отдельного выбора фаз нет; используются границы, которые Revit возвращает для каждого помещения.

## Повторные запуски и ограничения

- Ранее созданная этими тремя командами отделка распознаётся по служебной метке и пропускается. Обновления и замены существующей отделки в этом выпуске нет. Смена типа в таблице не изменяет уже созданные элементы. Чужая и вручную построенная отделка автоматически не распознаётся: возможные пересечения показываются в замечаниях Revit.
- Поддержаны прямые и дуговые горизонтальные контуры, внутренние отверстия, обычные вертикальные стены. Малые разрывы между прямыми до 1 мм совмещаются с явным замечанием; большие разрывы отклоняются.
- Для проёмов в прямых стенах используются фактические границы выреза, без наличников и дуг открывания. Прямоугольные и ступенчатые ортогональные вырезы семейств сохраняются; ступенчатая форма может состоять из нескольких прямоугольных вырезов Revit.
- Проёмы в дуговых стенах, арочные или наклонные границы вырезов, откосы, короба, наклонные полы/потолки и сложные профили стен не входят в этот выпуск. Неподдерживаемый проём приводит к пропуску всего помещения с пояснением, без частичной отделки стен.
- Витражи, колонны и линии разделения помещений не считаются основой для отделочных стен. Они могут участвовать в замкнутом контуре пола и потолка.
- Если удалён только один из нескольких участков отделки одной стены в одном помещении, оставшаяся служебная метка блокирует повторное создание этой основы. Для перестроения удалите все её отделочные участки в этом помещении и запустите команду заново.
