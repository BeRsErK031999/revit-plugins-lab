
2024 harness копирует исходные файлы, проверяет их хеши, временно регистрирует только свой add-in и останавливает только запущенный им процесс Revit. 2021 harness создаёт новую временную модель. При нативных проверках тестовый код содержит те же исходники геометрической отделки, что и приложение, чтобы установленная сборка TrueBIM другой версии не подменяла проверяемый код.
