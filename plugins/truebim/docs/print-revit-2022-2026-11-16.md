# Печать Revit 2022 — TrueBIM 0.2.59

Модель проверки: `ZUZ_1.4_TB_03_KM7-KM8_RD_R22.rvt` из пользовательской папки `Desktop/Revit/Печать`.
Исходный SHA-256: `8FCDD8A6CD3A727E766465BB2F37DC4B4C49965331B7E0981FB84DA43948CEFE`.
Проверка выполнена в отдельном Revit 2022.1 на отсоединённой копии без загрузки RVT-связей. Исходный файл не сохранялся; итоговый SHA-256 совпал с исходным.

## Причины

1. На предоставленном скриншоте PDFCreator не возвращает PDF в перенаправленный файл. В старом коде любой принтер с «PDF» в имени допускался к записи в папку, хотя преобразование не-PDF потока реализовано только для PDF24. Сам поток с исходного компьютера не предоставлен; конкретный формат этого потока не подтверждён.
2. Установленная локально сборка Revit 2022 имеет версию **0.2.52.0**. Возврат к уже использованному формату бумаги менял `CurrentPrintSetting` вне транзакции. Исправление `830e5e8`, выпущенное в **0.2.53**, уже находится в базе этого выпуска: выбор именованного формата выполняется внутри транзакции. Эта причина соответствует повторяющейся ошибке на скриншоте.
3. Первый нативный прогон дополнительно выявил ограничение длины пути Revit 2022 на листе 14. Длинное название прибавлялось к временному подкаталогу. Теперь Revit экспортирует короткий `output.pdf`, после чего файл публикуется с полным пользовательским именем. Укорочение не затрагивает имя результата.

Новый способ показан в подсказке окна до запуска и записывается в журнал. Именованные настройки стороннего драйвера не подменяются встроенным экспортом молча.
Встроенный экспорт доступен начиная с Revit 2022: [документация Autodesk](https://help.autodesk.com/cloudhelp/2022/ENU/Revit-DocumentPresent/files/GUID-773AD069-024B-425E-8B9A-05D5246BDD16.htm).

## Проверки

- Общий набор модульных тестов: **1318/1318**. После исправления временного имени повторно пройдены **140/140** тестов печати.
- Финальные Release-сборки: **Revit 2019–2027**, все девять DLL имеют версию **0.2.59.0**, манифесты проверены сборочным скриптом. В пакет не включаются Revit API DLL.
- В Revit 2022 получен **41 отдельный PDF** через маршрут PDFCreator. PdfPig проверил каждую страницу: размеры соответствуют основной надписи с допуском 1 мм, текст присутствует. Проверены стандартные и удлинённые форматы, включая лист 14 с длинным именем.
- Из окна плагина через тот же нативный маршрут при выбранном Adobe PDF создан общий файл: **41 страница**, 23 315 035 байт. PdfPig подтвердил текст на каждой странице и совпадение набора размеров с отдельными листами. Контрольные страницы просмотрены после рендеринга. SHA-256 общего файла: `08A14D933BE278C83358653A19E922055908636CE275FBD4792B0268AAB7195F`.
- В окне проверены завершение печати, подсказка нативного маршрута и блокировка кнопки с предупреждением при выборе ручной настройки стороннего драйвера.
- Финальный контроль `TRUEBIM_PRINT_ACCEPTANCE=state` подтвердил сохранение именованного пресета (портретная ориентация, оттенки серого, качество Presentation), а также переключение **A4 → A3 → A4** через `AutoSheetPrintLayout` без ошибки транзакции. Временные настройки откатились, новых пресетов в модели не осталось.
- Старый пресет модели `PDF24_Умолч 1` связан с отсутствующим на стенде драйвером: его ID и имя сохранились, прочитать бумажные параметры Revit не позволяет. Поэтому дополнительно создан и проверен совместимый тестовый пресет, затем он откатан.
- Логи, PDF, рендеры, TRX и отчёт сборки сохраняются локально в `tmp/release-0.2.59-print-2022` основного checkout; пользовательская модель и результаты печати в Git не включаются. Проверочный add-in удалён, локальный файл пресетов, созданный проверкой, убран из профиля Revit 2022.

## Текущие параметры сеанса

Встроенный экспорт Revit 2022 обновляет текущие, не сохранённые под именем параметры печати: в проверке ориентация стала `Auto`, качество — `High`. Первоначальная дополнительная проверка неизменности этих параметров выявила это штатное поведение. Восстановление через `Apply` и через временный пресет с откатом не дало надёжного результата; такой обход **не включён** в выпуск. Окно заранее предупреждает об обновлении текущих параметров. Сохранённые именованные настройки не перезаписываются — это проверено отдельно. При последующей обычной печати следует выбрать нужный сохранённый пресет.

## Границы

PDFCreator не установлен на проверочном компьютере. Проверяется новый путь для выбранного имени PDFCreator, который выполняется полностью внутри Revit и не требует драйвера. Печать через собственный диалог PDFCreator, физическая печать и запуск остальных версий Revit в этой работе не проверяются. Сборка по API не заменяет такие проверки.
Публикация установщика не означает его установку на рабочие места сотрудников.
