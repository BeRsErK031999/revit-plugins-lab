# Общий выпуск TrueBIM 0.2.35

Дата сверки: 21.10.2026. Этот выпуск фиксирует накопленные изменения в `main`
и пересобирает общий установщик из зафиксированного состояния репозитория.
Поддерживаемые этим пакетом версии: Revit 2021–2026. Revit 2019 и 2020
исключены: на машине сборки отсутствуют соответствующие Revit API.

| Область | Включённый результат других рабочих чатов |
|---|---|
| Ведомость отделки | Выбор между назначением принадлежности по геометрии и расчётом по сохранённым параметрам; сохранение ручных исправлений, откат при ошибке записи назначения. |
| Предыдущие исправления отделки | Исправления принадлежности стен, проверка пустых описаний, удаление архивирования, перенос текста средствами Revit. |
| Проверка ТЭП | Команда в АР, расчёт и сверка Excel; нулевые помещения пропускаются с диагностикой, неполные суммы помечаются `*` и жёлтой заливкой. |
| Разбить арматуру | Команда в КР; выбранные наборы либо все наборы переменных длин, перенос параметров, сохранение поддерживаемых аннотаций и исправленные ссылки размеров. |
| Обновить схему | Команда в ЭОМ, предпросмотр, выбор групп, диагностика и методичка. |
| Печать | «Целый лист DWG»: отдельный полный файл каждого листа без принудительного разбиения на XRef. |

| Ранее зафиксированные изменения | Все 26 коммитов `develop`, отсутствовавшие в `origin/main` перед этой сверкой, включая сворачивание ВРС, ведомость спецификаций и замену семейств. |

«Вернадского» 1.0.2 сохраняется как отдельный продукт для Revit 2024
с собственным установщиком; его исходники, тесты и документация также входят
в общий коммит. Материал читается из «Материал несущих конструкций»,
поддерживается `GP_Этаж` типа «Денежная единица», вкладка «Вернадского», панель «АР».
Исследование экспорта из САПФИР не содержало реализованного импортёра;
новая команда по этому исследованию в пакет не добавляется.

## Сверка последнего установщика 0.2.34

SHA256 файла `TrueBIM-Setup-0.2.34.exe`:
`C50ABD6D0916EFD61DB9480D409CC775A505D9EC10591937199BFB27AA7ECF8B`.
Он совпал с отчётом предыдущей сборки. Для каждого из шести сохранённых
payload-ов Revit 2021–2026 проверены SHA256 исходников из portable PDB:
**699 из 699 файлов совпали с текущими исходниками**. Дополнительных файлов
C# производственного приложения, отсутствующих в этой проверке, не найдено.
Это подтверждает включение текущего кода, в том числе незакоммиченных новых
модулей, в сохранённые сборки 0.2.34. Сам установщик повторно не запускался.

В старой рабочей копии `tmp/vrs-fix-0.2.11` код модуля
`ScheduleColumnCollapse` совпадает с основной копией; устаревшая версия
установщика и старые общие файлы из неё не переносятся поверх новых.
