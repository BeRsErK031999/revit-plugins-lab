# Замена семейств

Первый целевой контур: Revit 2022, один проект. Рабочий пример: экземпляры категории «Пожарная сигнализация» заменяются загруженным типом категории «Устройства вызова и оповещения».

## Запуск и выбор

- **TrueBIM → Координация → Замена семейств**.
- **Диспетчер семейств → выбрать семейство и тип → Заменить экземпляры…** открывает тот же инструмент с выбранным типом. Если тип ещё отсутствует в проекте, сначала используется существующая кнопка «Загрузить».
- Области поиска: активный вид, несколько выбранных видов, весь проект, предварительно выделенные экземпляры, ручной выбор в модели. Экземпляр на нескольких видах учитывается один раз; связи не обрабатываются.
- Дерево «категория → семейство → тип» показывает количество экземпляров. Поиск и подсветка используют общий механизм диспетчера семейств. Таблица справа позволяет уточнить отдельные экземпляры.
- Целевой тип выбирается среди уже загруженных семейств. По умолчанию предложена категория устройств вызова и оповещения. Автоматической подмены неоднозначного типа нет.
- Для аннотационных марок можно выбрать загруженный тип вручную. Автовыбор между категориями допустим только при единственном совместимом типе; многокатегорийная марка может сохранить исходный тип.

Диспетчер семейств продолжает владеть библиотеками `.rfa`, загрузкой, метаданными и изображениями. Новый инструмент отвечает за экземпляры проекта. Оба входа используют `FamilyReplacementWorkflow`; механизм замены не дублируется.

## Что означает сохранение положения

Используются координаты текущего проекта: преобразование общих координат не нужно, поскольку оба экземпляра находятся в одном документе.

Доступны два явных режима:

1. **По центру геометрии** — совпадает центр габаритов видимой объёмной геометрии в XYZ. Это центр ограничивающего прямоугольного объёма, а не центр масс. Символические линии не участвуют. Если объёмной геометрии нет, экземпляр пропускается с предложением выбрать точку вставки.
2. **По точке вставки** — сохраняется исходная точка размещения в XYZ.

Сначала переносятся параметры экземпляра, затем выполняется совмещение. Проверяются все три оси пространственной ориентации, включая отражение, исходный уровень и основа размещения. В режиме центра точка вставки и численное смещение от уровня могут измениться, если локальные начала семейств различаются: положение выбранного центра в модели сохраняется. Допуск положения — 0,1 мм.

Поддерживаются экземпляры с точкой размещения и одинаковым способом размещения: одноуровневые, одноуровневые на существующей основе, на рабочей плоскости при доступной исходной ссылке на грань. Окончательная проверка выполняется по фактическому результату Revit.

## Параметры и аннотации

- Переносятся `Марка`, `Комментарии` и редактируемые пользовательские параметры экземпляра, включая числовой ноль и выключенные Да/Нет.
- Общие параметры сопоставляются по GUID; встроенные — по идентификатору. Для прочих используется идентификатор параметра проекта или однозначное совпадение имени и типа данных. Разные GUID не объединяются по имени.
- Параметры выбранного типа не изменяются. Отсутствие заполненного исходного параметра у нового экземпляра приводит к отмене замены этого экземпляра; потеря значения не замалчивается.
- Сохраняются фазы, рабочий набор, вариант конструкции и закрепление. Подключённые инженерные системы автоматически не переносятся: такие экземпляры пропускаются.
- Линейные размеры пересоздаются по центральным или одноимённым опорным плоскостям. Проверяются численные значения и положение каждого сегмента до и после удаления оригинала; копируются тип, текстовые переопределения, положение текста, выноски и графика вида.
- Одноэлементные марки пересоздаются совместимым типом; проверяются ссылка на новый экземпляр, текст и положение. Сохраняются выноски, поворот и графика вида.
- Размеры по произвольным граням/рёбрам без соответствующей опорной плоскости, замкнутые/EQ/управляющие размеры, марки материалов и составные аннотации требуют ручной обработки. Ошибка сохранения аннотации отменяет весь перенос соответствующего экземпляра.
- Не обрабатываются экземпляры в группах/сборках, общие вложенные экземпляры и родители с общими вложенными экземплярами: перенос их отдельных параметров и связей требует самостоятельного сопоставления.

Каждый экземпляр заменяется отдельной транзакцией. Проверяется фактический список удалённых элементов; неожиданное каскадное удаление вызывает откат. Успешные замены объединяются в одно действие **Отменить**. Результат показывает исходное количество, число заменённых/пропущенных и причину по каждому ID. Новый запуск делает новый поиск, без фоновой синхронизации.

## Проверка в Revit 2022

### Исправление одиночного выделения — 0.2.13

В Revit 2022 воспроизведён отказ с текстом «Замена затрагивает дополнительные элементы»: при одном активно выделенном приборе `Document.Delete` сообщал дополнительные служебные ID. Без выделения тот же сценарий работал; массовая замена тоже проходила. Эти ID не входили в обычный список зависимых модельных элементов. Проверка сохранности поэтому откатывала одиночную замену.

Общий запуск из «Координации» и диспетчера теперь фиксирует исходные ID отдельно, очищает экранное выделение и обновляет вид перед транзакциями. После операции выделение восстанавливается с новыми ID успешно заменённых экземпляров. Пропущенные и посторонние выделенные элементы сохраняются в выделении. При ошибке восстанавливается исходное выделение. Проверка дополнительных удалений и защита настоящих аннотаций не ослаблены.

Проверено внутри Revit 2022 на созданной тестовой модели: старый одиночный сценарий — 0/1, старый массовый — 2/2, одиночный без выделения — 1/1, исправленный одиночный — 1/1. Дополнительно прошли 93 теста логики и интеграции интерфейса. Повторяемая проверка: `plugins/truebim/scripts/test-family-replacement-2022.ps1`.

### Первоначальная версия

Проверки реализации от 2026-09-15:

- Release-сборка `net48` против установленной Revit API 2022: 0 ошибок, 0 предупреждений.
- 87 тестов фильтрации, сопоставления параметров, диспетчера семейств и регистрации кнопок: пройдены. Это тесты логики на `.NET 8`, а не выполнение замен внутри Revit.
- WPF-окно отрисовано на демонстрационных 83 экземплярах при ширине 1190 и 960 пикселей; область выбора, настройки и кнопка применения доступны.
- Реальная замена в Revit 2022 на пользовательских семействах пока не проверена.

Автоматическая сборка и тесты логики сопоставления не подтверждают поведение конкретных `.rfa`. Перед применением к рабочему проекту выполнить следующие проверки на копии проекта:

| Проверка | Ожидаемый результат |
| --- | --- |
| Один исходный прибор, заполненные Марка/Комментарии, ненулевое смещение от уровня | Тип и категория меняются; значения, уровень и выбранная точка сохраняются |
| Повороты 0°, 90°, 37°, отражённые экземпляры | Сохраняется полная пространственная ориентация |
| Разные локальные начала семейств | Режим центра сохраняет центр габаритов; режим точки сохраняет точку вставки |
| Одинаковый прибор виден на двух выбранных видах | В результат попадает один раз |
| Поиск конкретного семейства, выбор нескольких строк | Меняются только выбранные элементы текущего фильтра |
| Размер по центральной плоскости и обычная марка | Размерное значение, текст, положение и привязки сохранены |
| Один размер соединяет два заменяемых прибора | После обеих замен обе ссылки действительны, значение не меняется |
| Несколько типов марок новой категории | Требуется явный тип; затем замена проходит при совпадении текста |
| Нет целевого параметра, несовместимый хост или потеря размерной ссылки | Исходный прибор и его аннотации остаются; причина в отчёте |
| Сбой одного прибора среди нескольких | Другие допустимые приборы заменены; неудачный полностью восстановлен |
| Отменить в Revit | Восстанавливаются исходные экземпляры и аннотации всей операции |
| Запуск из диспетчера | Открывается тот же выбор экземпляров с нужным целевым типом |

Исходная техническая документация: локальная XML-справка Revit API 2022; [Autodesk — FamilyInstances](https://help.autodesk.com/cloudhelp/2016/ENU/Revit-API/files/GUID-C7E4C845-C386-4B7B-BDA1-5D2BE7A5C2D8.htm). Решения проверяются компиляцией против установленной Revit API 2022.
