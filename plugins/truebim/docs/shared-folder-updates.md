# Обновление TrueBIM из общей папки

Начиная с 0.2.52, в ленте **TrueBIM → Помощь → Проверить обновления** есть отдельная кнопка. Она доступна и без открытой модели. Источник — `W:\Shared\RevitPlugins\TrueBIM-release.json`.

## Для сотрудника

1. Один раз установить 0.2.52 или более новую версию обычным установщиком: в выпусках до 0.2.52 кнопки ещё нет.
2. Нажать «Проверить обновления». Окно показывает установленную и опубликованную версии.
3. Если новая версия доступна, нажать «Обновить». Установщик копируется в локальный профиль и проверяется.
4. После появления помощника сохранить модели и закрыть все окна Revit. Помощник не закрывает программы и не сохраняет модели за пользователя.
5. Дождаться сообщения об успешной установке и открыть Revit снова. Передумав, можно отменить ожидание в окне помощника. Во время самой установки кнопка закрытия временно недоступна.

Недоступность диска или повреждение описания/установщика не меняет установленную версию. Окно проверки остаётся отзывчивым и сообщает об ошибке. Более старую или ту же версию кнопка не устанавливает. Обновляются версии Revit, в которых TrueBIM уже установлен, включая текущую; настройка пользовательских параметров не удаляется установщиком.

Помощник работает независимо от Revit. Он повторно проверяет локальный EXE непосредственно перед запуском и удерживает его открытым для чтения, запрещая подмену/изменение на время запуска и установки. Установщик отдельно проверяет запущенные процессы Revit и отказывается устанавливать, пока они есть; автоматическое закрытие и перезапуск приложений отключены. Не открывать Revit повторно до завершения установки.

Локальные файлы и журналы: `%LOCALAPPDATA%\TrueBIM\Updates\<идентификатор>\` (`update.log`, `installer.log`). Общие ошибки проверки доступны через «Логи» TrueBIM. В манифесте нет пользовательских данных; клиент только читает общую папку.

## Публикация выпуска

В каталоге лежат версионные EXE и `TrueBIM-release.json`:

```json
{
  "schemaVersion": 1,
  "product": "TrueBIM",
  "latest": { "version": "0.2.52", "file": "TrueBIM-Setup-0.2.52.exe", "sha256": "<SHA-256 файла>" },
  "previous": { "version": "0.2.51", "file": "TrueBIM-Setup-0.2.51.exe", "sha256": "<SHA-256 файла>" }
}
```

Версия приложения и помощника задаётся в `plugins/truebim/Version.props`; тот же номер указывается в `installer/TrueBIM.iss`. Сборщик проверяет их совпадение. После проверки сборки и Git push выполнить:

```powershell
plugins/truebim/scripts/publish-release.ps1
```

Скрипт проверяет версии и хеши, копирует EXE под временным именем, затем публикует версионный файл и последним заменяет манифест. Предыдущая актуальная версия становится резервной. Повторная публикация той же версии с тем же содержимым сохраняет резервную версию; изменение содержимого уже опубликованного номера отклоняется. Старые EXE автоматически не удаляются. Для локальной репетиции можно передать `-ReleaseDirectory`.

Папка публикации должна быть доступна сотрудникам на чтение, а изменение файлов и манифеста — ответственным за выпуск. SHA-256 защищает от повреждения и несогласованной копии; это не цифровая подпись издателя. Права на общую папку клиент не меняет.

Откат при необходимости выполняется вручную предыдущим установщиком после закрытия Revit. Автоматический откат через кнопку не предусмотрен.
