# Сворачивание ВРС · исправление от 05.11.2026

## Изменение

Команда «Свернуть ВРС» обрабатывает только числовые поля, имена которых начинаются с `Р • ИА…` или `Р • ИЗ…`. Выбор не зависит от текста заголовка колонки. Поля вне этих префиксов, текстовые поля и поля фильтрации/сортировки сохраняют исходную видимость. Нулевые и пустые целевые столбцы скрываются, ненулевые показываются; нераспознанные значения без подтверждённого ненулевого значения сохраняют видимость.

В модели пользователя Revit возвращает пять строк многоуровневой шапки через `SectionType.Body`. Ранее тексты «ГОСТ 34028-2016», «А240» и другие групповые заголовки попадали в анализ данных как нераспознанные значения, поэтому нулевые колонки сохраняли видимость. При чтении теперь временно выключаются `ShowHeaders`/`ShowTitle` и раскрываются только целевые поля. Вся подготовка чтения откатывается через `SubTransaction` перед применением видимости; заголовки не определяются по совпадению текста с числом.

## Повторение

```powershell
plugins/truebim/scripts/test-schedule-collapse-2024.ps1
dotnet test plugins/truebim/tests/TrueBIM.App.Tests/TrueBIM.App.Tests.csproj -c Release -p:RevitVersion=2025
```

Нативный harness рассчитан на указанную контрольную модель. Он копирует исходник, проверяет SHA-256, регистрирует временный add-in, использует сборку текущего кода с отдельным именем и завершает только собственный процесс Revit. При стартовых предупреждениях сторонних надстроек может понадобиться действие пользователя.
