# Разбить арматуру: защита закрепления и групп — 0.2.41

Дата проверки: 21.10.2026.

## Исправленное поведение

Если среди обрабатываемых наборов есть закреплённый или входящий в группу,
Revit показывает своё штатное предупреждение и целиком отменяет разбиение. Проверка выполняется
до начала изменений и непосредственно перед каждым удалением исходника.
Открепление, извлечение из группы, разгруппировка и автоматический пропуск
защищённых наборов не выполняются. Вариант «Всё равно разбить» для ошибок
переноса параметров не обходит защиту.

Причина прежнего поведения: Revit API `Document.Delete` удаляет закреплённые
элементы без предупреждения, что явно указано в XML-документации Autodesk
к этому методу. Предварительного открепления в плагине не было. Новые стержни
создавались отдельно и не наследовали принадлежность исходного набора к группе.

Команда передаёт `EditingFailures.PinnedObjectNotDeleted` (Warning) и
`EditingFailures.DeletePreventedByGroup` (Error) через `Document.PostFailure`.
Встроенные сообщения содержат ID соответствующих исходников. Транзакция
откатывается с `SetForcedModalHandling(true)` и `SetClearAfterRollback(false)`.
Это стандартный механизм ошибок Revit: собственный диалог плагина для
закрепления и групп не создаётся. Кнопка OK в проверенном диалоге закрепления
недоступна, доступна отмена. Ограничения не разрешаются автоматически.

API: [поведение сообщений при откате](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/bebe6efd-b05f-7a0b-4cc3-609ec35be42c.htm).

## Нативные проверки Revit 2022

Все проверки выполнены отдельным процессом Revit Viewer. Тестовые изменения
откатываются; рабочая модель и установленный плагин не обновлялись.

**18/18 проверок защиты:** обычный набор, закреплённый набор, группа,
повторяющиеся экземпляры группы, закреплённая группа и смешанный выбор,
с включённым и выключенным сохранением аннотаций. Для защищённых наборов
совпали ID, геометрия, параметры, закрепление, типы и состав групп. В смешанном
выборе обычный набор, поставленный первым, также остался без изменений.
Обычная арматура успешно разбивается.

Дополнительно проверены точные встроенные ID ошибок и наборы проблемных
элементов. Только тестовый стенд перехватывает сообщения для автоматического
отката; в рабочей команде перехвата или подавления нет. Временный стенд также
убирает ожидаемое предупреждение о повторяющихся марках тестовых стержней.

Отчёт: `test-results/rebar-split/revit-2022-f9475dcacb0b4bfeaea634642b3b490c.json`.

**12/12 сценариев на копии `Тест_rvt22.rvt`:**

- В модели 9 наборов. Шесть закреплены, из них четыре входят в две группы.
- Для обработки всех выбранных наборов и всех наборов с разными фактическими
  длинами операция отклонена. Во всех восьми сочетаниях области, галочки
  аннотаций и открытого вида совпали ID и `VersionGuid` всех 15 838 элементов.
  Группы, исходная арматура и аннотации остались без изменений.
- При отдельном выборе трёх незакреплённых наборов вне групп получены 15
  одиночных стержней. Геометрия и параметры прошли проверки во всех четырёх
  сочетаниях галочки аннотаций и открытого вида.
- С включённым сохранением аннотаций число размеров осталось 2378;
  мультиарматурная аннотация — одна. Для обычных размеров `2031028` и `2031090`
  подтверждены новые привязки, значения, текст и оформление; на открытом виде
  Revit также подтвердил доступность ссылок. Количество мультиарматурных
  аннотаций само по себе не доказывает корректность всех их ссылок.
- При выключенной галочке оформление не восстанавливалось, как и предусмотрено
  этой опцией. После каждого сценария изменения модели полностью откатывались.

## Общий пакет

Все восемь сборок Revit 2019–2026 выполнены из единого снимка текущих исходников.
Сохранены компактная лента, снятие ограничения количества значений в «Цветах
по параметрам» и остальные команды. Для каждой сборки сверены SHA-256 всех
703 файлов исходников приложения, записанных в PDB, со снимком и рабочими
файлами. Проверено наличие трёх дополнительных модулей, манифестов нужных
версий и отсутствие поставки RevitAPI DLL.

Все 1168 модульных тестов прошли: `test-results/rebar-split/release-0.2.41/rebar-native-final.trx`.
Нативная проверка в других версиях Revit не выполнялась.
