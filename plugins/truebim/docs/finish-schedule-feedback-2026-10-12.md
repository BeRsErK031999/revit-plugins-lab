# Ведомость отделки и фильтры окраски — 0.2.26

Исправления по замечаниям от 8–9 октября 2026 года.

## Формирование ведомости

Каждый запуск создаёт новый вид спецификации со стандартным оформлением. Если имя занято, добавляется номер в скобках. Описания, площади и принадлежность записываются в существующие параметры, выбранные в конфигурации. Подтверждение перезаписи больше не появляется.

Новый выпуск не создаёт комплект служебных параметров, не копирует предыдущие значения и не архивирует прежние спецификации. Новые спецификации читают текущие параметры помещений, поэтому изменение этих параметров отображается во всех читающих их спецификациях. Архивы и параметры, ранее созданные старыми версиями, автоматически не удаляются.

Перед расчётом проверяется заполнение выбранного параметра описания у типов размещённых отделочных элементов включённых категорий. Неиспользуемые типы и типы конструктивных элементов в список не попадают. В предупреждении каждый тип указан один раз: название и ID типоразмера. Список допускает выделение мышью и копирование. «Отмена» завершает операцию до расчёта и записи, «Продолжить» допускает маркер `[Описание не задано]`.

## Причина ошибок принадлежности

Прежний алгоритм выбирал помещение с наибольшей площадью контакта с отделкой. На стыках тонких отделочных стен грани имеют разную длину: торец или подрезка уменьшает контакт со стороны внутреннего помещения. Платформа 210 получала небольшой перевес, хотя соседние участки единого контура отделки однозначно относились к 211 или 213.

| Элемент | Контакт с 210, м² | Контакт с правильным помещением, м² | Правильное помещение | Полная площадь Revit, м² |
|---|---:|---:|---|---:|
| 2421343 | 1,134 | 1,026 | 211, ID 2002199 | 1,134 |
| 2445594 | 1,2474 | 1,1286 | 213, ID 2308808 | 1,2474 |
| 2445806 | 24,087031 | 24,028763 | 213, ID 2308808 | 24,147563 |
| 2445891 | 1,188 | 1,0692 | 213, ID 2308808 | 1,188 |

Теперь при разнице контактов не больше площади торца стены алгоритм проверяет соединённые участки того же типа на том же уровне. При единственном подтверждённом помещении соседних участков и наличии контакта с ним у всей спорной цепочки принадлежность определяется по контуру. Если соседи указывают на разные помещения, такое уточнение не применяется. Это геометрическое правило; ID из обращения не зашиты в рабочий алгоритм.

Диагностика в полном отчёте теперь включает причины выбора, ID помещений, площади контактов и методы их получения. Площадь контакта нужна только для определения принадлежности: в итог всегда попадает полная системная площадь элемента, ровно один раз.

## Переносы и площади

Раньше плагин оценивал вместимость строки по средней ширине символа (`0,58 × размер текста`) и вставлял переносы в само значение параметра. Оценка не учитывала реальную ширину букв конкретного шрифта, из-за чего Revit мог дополнительно переносить уже разбитый текст.

Теперь описание внутри одного вида отделки остаётся цельным: автоматический перенос выполняет Revit. Между двумя видами отделки вставляются два перевода строки с сохраняемым пустым разделителем. В столбце площади используется такой же разделитель; дополнительные пустые строки для выравнивания рассчитываются по метрикам выбранного шрифта, его размеру и ширине столбца. Ручное изменение ширины или шрифта уже созданной спецификации не пересчитывает записанные отступы — для стандартного оформления следует сформировать новую ведомость.

Revit удаляет пробельные строки по краям текстового параметра, включая неразрывные пробелы. Поэтому строки отступов площади содержат невидимый символ нулевой ширины U+200B: он сохраняет начальные и конечные отступы при записи, не добавляя печатных знаков. Это проверено сравнением записанного параметра с рассчитанным значением и экспортом листа.

## Удаление фильтров

В инструменте «Цвета по параметрам» добавлена вкладка «Удаление фильтров». Она показывает фильтры `BIM_F_` всего проекта: флажок, название, категории и фактическое правило. Есть команды «Отметить все», «Снять все», «Обновить» и «Удалить выбранные».

Удаление убирает выбранные определения фильтров из проекта, включая их использование на видах и в шаблонах. Перед удалением повторно проверяется, что выбранные ID по-прежнему принадлежат фильтрам `BIM_F_`. Посторонние и неотмеченные фильтры сохраняются. Операция выполняется одной транзакцией и доступна для отмены в Revit.

## Проверка

На отсоединённой копии `D085_П_АР_ALL_rvt23_тест_Отделки.rvt` в Revit 2023 подтверждены все четыре исправления. По сравнению с исходным расчётом изменились только эти четыре принадлежности. Сохранены 692 учтённых элемента, их полные системные площади и отсутствие двойного учёта.

Автоматические проверки включают повторное создание спецификации без увеличения числа параметров, живую связь с настроенными параметрами, копируемый список пустых описаний на уровне данных, разделение текстовых блоков, сохранение полной площади и пакетное удаление только выбранных фильтров.

Полный набор модульных тестов: **1104 пройдено, 0 ошибок**. Финальный прогон в обычном режиме Revit 2023: **117 проверок пройдено**, включая модель, параметры, повторное формирование, удаление фильтров, сохранение отступов площади и экспорт листа. Визуально проверены длинные описания полов в 209–210 и несколько видов потолочной отделки в 101–104: разделители сохранены, площади расположены напротив своих блоков.

Артефакты финального прогона: `plugins/truebim/test-results/finish-model/2b599ed10100436eb79ea05a56bf07e0/` — `report.json`, `report.json.checks.json`, аудит геометрии и изображение листа. В `test-finish-model-2023.ps1` также исправлено поведение при тайм-ауте/ошибке: тестовый Revit остаётся открытым для диагностики. После успешной проверки тестовый экземпляр закрывается штатно.
