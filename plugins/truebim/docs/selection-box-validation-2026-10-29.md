## Что проверено в Revit

1. Получение предварительного выбора из четырёх ссылок: один элемент основной модели
   и по одному элементу трёх RVT-связей. Отдельно проверены все восемь углов каждого габарита.
2. Перемещение и поворот экземпляров связей, соответствие координат габарита
   трансформации каждого экземпляра.
3. Создание отсутствующего `{3D}` штатной командой Revit и автоматическое применение
   рамки по выбору, зафиксированному до переключения вида.
4. Повторное использование активного, открытого и закрытого существующего 3D-вида.
5. Запуск с плана, листа, спецификации и разреза; отсутствие ограничений команды по
   исходному типу вида. Фасад отдельно в этом наборе не проверялся.
6. Сохранение шаблона, детализации, стиля отображения и направления камеры.
7. Точное обрамление выбранных габаритов с отступом 300 мм на каждой из шести граней,
   в том числе после поворота рамки и зеркального отражения связи.
8. Отсутствие временной изоляции; пустой и неподходящий выбор не меняет рамку.
9. Создание `{3D - имя пользователя}` после включения совместной работы на тестовой
   копии и повторное открытие этого вида без дубликатов.

Предварительный выбор в тесте задавался через `Selection.SetReferences()`; ручная
последовательность Tab/Ctrl и нажатие именно основной кнопки на рабочей ленте отдельно
не проверялись. Проверочный сценарий вызывал тот же `SelectionBoxRequest.Start()`
в контексте обычной внешней команды Revit. Размещение основной кнопки проверено автотестами ленты.

## Исправления, выявленные проверкой

- Синхронная смена активного вида недоступна в `Idling`. Проверка существующих видов
  выполняется обычной внешней командой; фоновое завершение создания стандартного вида
  только меняет рамку уже активированного штатной командой вида.
- API запрещает вручную присваивать имена с фигурными скобками. Отказались от создания
  обычного вида с последующим переименованием: стандартный вид создаёт сам Revit через
  `PostableCommand.Default3DView`, после чего плагин применяет сохранённые габариты.

Предварительная тестовая сборка 0.2.43, выданная до завершения нативной проверки,
заменена исправленным установщиком с тем же номером. Для установки использовать
окончательный `dist/installer/TrueBIM-Setup-0.2.43.exe` и соседний SHA-256.

## Границы проверки

- Работа с предварительным выбором связей поддерживается в Revit 2023–2026.
  В Revit 2019–2022 кнопка выводит согласованное сообщение об ограничении API.
- Нативный прогон выполнен только в Revit 2024.3; остальные версии проверены сборкой.
- Вложенные связи не входят в поддерживаемый сценарий; выбранная вложенная связь
  отклоняется с пояснением. Незагруженная связь и элементы без модельного габарита
  не подменяются габаритом всей родительской связи.
- Конфликт владения видом с другим пользователем, перспективный вид и шаблон,
  принудительно запрещающий рамку, не воспроизводились отдельными тестами.
- Установщик собран, но его установка/удаление в этой задаче не выполнялись.
