# Обновление на терминальном сервере — 0.2.56

## Ошибка и исправление

В 0.2.55 любой `Revit.exe` или `RevitCoreConsole.exe` без доступного SID владельца вызывал исключение и отключал кнопку завершения, даже если процесс находился в чужом сеансе. В 0.2.56 установщик и помощник применяют одинаковую политику:

| Владелец | Сеанс | Поведение |
| --- | --- | --- |
| Текущий пользователь | Любой, включая отключённый | Ждать закрытия; в ручном установщике можно подтвердить завершение |
| Другой пользователь | Любой | Не блокировать и не завершать |
| Недоступен | Текущий | Блокировать, показать PID/сеанс, закрывать только вручную |
| Недоступен | Другой | Не считать своим; перейти к проверке файлов своего профиля |
| Не определён текущий пользователь или не получен снимок | Любой | Остановить установку с ошибкой |

Отсутствие SID не доказывает, что процесс чужой. Поэтому `PrepareToInstall` до `[InstallDelete]` и копирования проверяет все существующие файлы выбранных каталогов `%APPDATA%\TrueBIM\<год>` и соответствующие `TrueBIM.addin`. `CreateFileW` с `OPEN_EXISTING` запрашивает доступ для записи/удаления и сразу закрывает дескриптор: содержимое не меняется. Блокировка, загруженная DLL или ошибка доступа останавливают установку. Это также защищает профиль, если недоступный процесс другого сеанса принадлежит той же учётной записи. Ссылки на вложенные каталоги не обходятся; установка останавливается с диагностикой.

Перед принудительным завершением повторно проверяются SID, имя и время запуска процесса. Неизвестные владельцы не попадают в подтверждение. Тихая установка никогда не завершает процессы. Проверка не резервирует файлы до конца установки: как и раньше, нельзя запускать Revit повторно во время обновления.

Документация API: [Microsoft: перечисление процессов по SID и сеансу](https://learn.microsoft.com/en-us/windows/win32/procthread/process-enumeration), [ограничения WTSEnumerateProcessesW](https://learn.microsoft.com/en-us/windows/win32/api/wtsapi32/nf-wtsapi32-wtsenumerateprocessesw), [CreateFileW: доступ и совместное открытие](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew).

## Проверки 13.11.2026

- 44 теста обновлений `TrueBIM.App.Tests` прошли, в том числе матрица владельцев/сеансов и смешанный снимок с неизвестным владельцем; нативный WTS проверен на двух типах собственных процессов-заглушек.
- `tests/installer/test-process-guard.ps1`: 11 сценариев прошли. Нет процессов, посторонний процесс, Revit, CoreConsole, несколько процессов; свободные файлы, блокировка записи, блокировка удаления, readonly, освобождённый файл, DLL, реально загруженная отдельным процессом .NET Framework 4.8.
- Тот же Pascal-код фильтрации и допуска к завершению проверяется встроенной матрицей тестового установщика. Собственный SID в другом сеансе учитывается; неизвестный SID в другом сеансе не вызывает исключение; неизвестный SID в текущем сеансе блокирует и не допускает завершения.
- Заблокированные сценарии возвращают код 7, свободные — 0. Тихий режим оставляет процессы работать. Хеш проверяемой DLL не меняется; путь занятого файла присутствует в диагностике.
- В окне мастера проверены читаемость, PID/сеансы, подтверждение с «Нет» по умолчанию, отказ без завершения процессов, завершение двух собственных заглушек после «Да» и успешное продолжение. Посторонняя заглушка осталась работать. Отдельно проверены сообщение о загруженной DLL, недоступная кнопка завершения при отсутствии собственных Revit и успешная повторная проверка после освобождения файла.
- Сборки для Revit 2019–2027 и установщик скомпилированы без ошибок; приложение и помощник имеют версию 0.2.56. Предупреждения об устаревших API Revit 2021 относятся к существующему модулю армирования.

Тестовые снимки моделируют несколько пользователей и сеансов. Живой многопользовательский Windows Server/RDS и отключённый сеанс другого пользователя не проверены. Модели Revit эти тесты не открывают и не изменяют.

## Переход со старых версий

Старый помощник запускается из установленной версии плагина. Публикация нового манифеста не заменяет уже запущенный код. Если 0.2.52–0.2.55 блокирует обновление, отменить ожидание и один раз запустить `W:\Shared\RevitPlugins\TrueBIM-Setup-0.2.56.exe` вручную. После установки новой версии помощник использует исправленную проверку. Предыдущий выпуск 0.2.55 сохраняется для ручного возврата.
