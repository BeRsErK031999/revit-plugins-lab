Подготовлен единый кандидат 0.2.46 для API Revit 2019–2026; итоговая сборка
фиксируется в `dist/build-report.json` и отчёте рядом с установщиком.
Все восемь сборок прошли; Portable PDB каждой сборки подтверждает соответствие
всех 730 производственных C#-файлов текущим исходникам. Для Revit 2021 остаются
восемь прежних предупреждений CS0618 в `IsoFieldFamilyAnchorageReader.cs`;

сборка. Семейства автоматически не загружаются; их отсутствие сообщается
пользователю. Шпильки являются элементами оформления вида, а не модельной арматурой.
