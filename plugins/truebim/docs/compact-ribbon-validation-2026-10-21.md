# Проверка компактной ленты — 2026-10-21

Реализован выбранный вариант №3: одна вкладка TrueBIM с четырьмя панелями.
Все 27 исходных определений инструментов доступны через новую компоновку;
вложенные команды «Видимости» и «Фасадов проёмов» сохранены.

## Сборка и установка

- 45 тестов ленты и связанных ограничений команд пройдены.
- Сборки Revit 2021–2026 выполнены с соответствующими API: net48 для 2021–2024,
  net8.0-windows для 2025–2026.
- Локальные DLL в `%APPDATA%\TrueBIM\<год>` обновлены для всех шести версий.
  SHA-256 совпадают со сборками; прежние DLL и манифесты сохранены в резервных копиях.
- Файловая проверка установки и манифестов пройдена для всех шести версий.
- Подготовлен установщик 0.2.40. Revit 2019–2020 исключены: соответствующие API
  отсутствуют. Публикация релиза и автообновления не выполнялись.

## Проверка интерфейса

Проверка выполнена в Revit 2021.1.10, в режиме просмотра, на новом проекте
из шаблона строительства. Рабочие модели не открывались.

| Сценарий | Результат |
| --- | --- |
| Вкладка TrueBIM | Четыре панели, компактные трёхстрочные группы; ширина около 670 пикселей в проверенном окне |
| Модель / Параметры / Документы / Разделы | Все четыре меню раскрываются, подписи полностью видны, разделители показаны |
| Видимость | Полный список категорий раскрывается из трёхстрочной группы |
| Фасадные маркеры | Выключены и включены обратно; маркеры исчезают и возвращаются, значок пункта обновляется |
| Фасады проёмов | Создание, оформление и методичка присутствуют; оформление недоступно на плане |
| Цвета по параметрам — быстрый доступ | Команда вызвана; на пустом проекте штатно сообщает об отсутствии подходящих элементов |
| Печать — быстрый доступ | Окно «Печать и экспорт» открывается; печать и экспорт не запускались |

Нативная проверка UI относится к Revit 2021. Для 2022–2026 проверены сборки
и установленные файлы; отдельные UI-сеансы не выполнялись.
