# Ручная принадлежность отделки: проверка 21.10.2026

## Причина обращения

В `D085_П_АР_ALL_rvt23_тест_Отделки.rvt` пользователь заменил только параметр
`Отделка стен • Номер помещения`: 301 → 802 у четырёх стен и 213 → 320 у четырнадцати.
Стандартные номера самих помещений остались 301 и 213; помещений 802 и 320 в файле нет.
При выключенной записи принадлежности эти значения не удаётся сопоставить с помещениями.
Площадь таких элементов исключается из ведомости, ручные значения сохраняются.

Ошибка интерфейса скрывала причину: предупреждение `StoredOwnershipUnresolved`
сворачивалось в общий текст «Геометрических замечаний для стен», теряя введённый номер.
Геометрический поиск в этом режиме не выполнялся.

## Исправление

- Сообщения группируются по конкретной причине и значению принадлежности.
  Для 802 и 320 выводятся отдельные предупреждения с количеством стен и их ID.
- Пустые и неоднозначные значения также объясняются отдельно.
- Сообщение указывает, с каким параметром самого помещения сверяется принадлежность.
- При расчёте по сохранённым значениям больше нет советов проверять геометрический
  контакт полов и потолков. Нижний статус ссылается на причины исключения отделки.
- Встроенная методичка объясняет разницу между переносом отделки и перенумерацией помещения.

Алгоритм не создаёт помещения из произвольных номеров и не восстанавливает связь по
геометрии при снятой галочке. Для переноса указывают идентификатор существующего
помещения. Для перенумерации меняют также идентификатор самого помещения и сохраняют
согласованную принадлежность его стен, полов и потолков.

## Проверка в Revit 2023

Использована отдельная отсоединённая копия модели. Прогон:
`plugins/truebim/test-results/finish-model/ed4de1ffae7040d2ba26afc9c750ebc4`.
Пройдены 1674 проверки, включая все 18 ID из обращения, стандартный перенос между
существующими помещениями для стен, полов и потолков и откат при ошибке записи.

| Сценарий | Учтено стен | Площадь стен, м² |
| --- | ---: | ---: |
| До ручного изменения | 520 | 5801,76 |
| Только принадлежность стен 802 / 320 | 502 | 5519,69 |
| Дополнительно перенумерованы сами помещения | 520 | 5801,76 |

Исключённые 18 стен дают ровно 282,071248 м². Значение 5519,69 м² совпадает со
скриншотом обращения. Проверены реальные значения параметров и текст действующей
спецификации: при исключении стен обновились 11 значений помещений; спецификация
изменилась. После перенумерации появились номера 802 и 320, все 18 стен вернулись в
расчёт, их ручные значения не перезаписывались. В других категориях остались
предупреждения для прежних номеров — при перенумерации их принадлежность тоже нужно обновить.

Произвольный номер у стены сам по себе не меняет номер помещения в списке ведомости.
Существующий вид спецификации читает параметры помещений и обновляется вместе с ними.

Полный набор модульных тестов: 1160 успешно. Встроенная инструкция проверена
визуально через рендеринг WPF при ширине 720 px. Изменения расчёта и записи проверены
в Revit 2023; остальные версии проверяются сборкой, а не нативным запуском.
