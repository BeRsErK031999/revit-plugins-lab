# Оформление сечений — переработка 0.2.44

## Основание

Использованы `Дополнение.docx`, оба видео — «Оформление вертикального сечения» и «Оформление горизонтального узла» — и обновлённая модель из папки «Замечания». Звуковая дорожка разобрана локально, действия сопоставлены с кадрами и сохранёнными ручными видами.

## Изменения по замечаниям

- Размерные цепочки объединяют соседние наборы арматуры и привязки к граням. В контрольном разрезе получены `50 + 12×200=2400 + 200 + 180 + 50`, наружная цепочка `2880 + 250 + 750` и нижняя привязка `55 + 190 + 55` с общим размером `300`.
- Отступы размерных рядов заданы в миллиметрах на бумаге: 8 мм. Короткие смешанные последовательности горизонтального узла остаются отдельными размерами; равные последовательности от четырёх промежутков объединяются.
- Марки подбираются по назначению. Продольная арматура получает марку с шагом; небольшая группа — с количеством; фоновая поперечная арматура вертикального разреза — повёрнутую марку без полки. Число стержней учитывает обрывы видимой части.
- Количество записывается в «Комментарии» только при включённой галочке. Допустимы пустые значения и прежнее количество вида `4 шт.`; ручной текст, связанные, закреплённые и сгруппированные элементы сохраняются.
- Вместо общих границ всей модели используются местные границы армирования. Раскладка учитывает полки марок, размерный текст, ручные подписи, зеркальность угла и фактические точки присоединения выносок. Марки с засечками учитывают перемещение точки привязки вдоль стержней. Для плотного угла с длинным комментарием используется внешняя сторона; добавляются свободные ряды и проверяется взаимная перестановка подписей.
- Создаются обрывы, швы бетонирования и подписи плит из загруженных семейств. Подпись фундаментной плиты берёт обозначение связанной модели. Повторный запуск заменяет только созданные командой детали; ручные детали сохраняются.
- Окно команды содержит отдельные галочки деталей и записи количества. Убрано неиспользуемое поле типа мультиарматурной аннотации; типы марки и отметки обозначены как резервные.

## Границы результата

Автоматическая раскладка не воспроизводит каждое ручное перемещение из видео. Перед выпуском листа необходимо проверить оформление и положение вида. Особенно плотные узлы, дополнительные ручные линии и нетипичные семейства могут потребовать ручной доводки.

В «Узле 18» оси соседних наборов отличаются на 2 мм: поперечная цепочка содержит `53 + 2 + 190 + 2 + 53`. Это измерение предоставленной геометрии, а не подстановка защитного слоя `55`; мелкие размерные подписи требуют внимания при подготовке листа. В «Узле 13» длинная подпись П-образного стержня расположена снаружи угла, а часть других марок — над ним.

Общее поле «Комментарии» принадлежит элементу модели: если один набор оформляется в нескольких видах с разной обрезкой, после пакетного запуска остаётся количество последнего обработанного вида. Чтобы сохранить параметры модели, отключите запись количества.

Семейства деталей автоматически не загружаются. При отсутствии необходимых типов команда сообщает о пропуске. Нативная приёмка относится к Revit 2024 и предоставленной модели; совместимость остальных версий подтверждается сборкой против их API.

Установщик версии 0.2.44 подготовлен отдельно; рабочая установка автоматически не заменялась. Предыдущий пакет 0.2.43 сохранён.
