# Заполнятор арматуры — Revit 2019

Команда: **TrueBIM → КР → Заполнятор арматуры**.

Заполняет один выбранный параметр экземпляра у выбранной арматуры. Поддерживает обычную арматуру, общие вложенные семейства категории «Несущая арматура» и стержни `RebarInSystem`. Вложенность, тип семейства и принадлежность системе армирования сохраняются.

## Порядок работы

1. Выделите нужную арматуру в спецификации либо на плане/3D-виде. Выбранная строка, объединяющая несколько экземпляров, может передавать Revit несколько элементов — проверяйте список ID в окне команды.
2. Можно выбрать родительскую «Обобщённую модель»: команда найдёт арматуру во всех доступных уровнях её вложенности. Выбор непосредственно вложенного стержня обрабатывает только его, не соседей.
3. Запустите команду. Посторонние элементы выделения будут исключены. Выбор всей системы армирования по площади не разворачивается в стержни: выберите нужные стержни заранее.
4. В фильтре «Стержни: семейство / тип» выберите нужный тип, например прямые стержни каркаса. Галочками в первом столбце отметьте конкретные стержни. Кнопки «Отметить показанные» и «Снять показанные» действуют только на строки текущего фильтра. **Заполняются только отмеченные видимые строки; скрытые стержни не изменяются, даже если их галочки установлены.** По умолчанию все строки отмечены. Галочки сохраняются при переключении фильтра и параметра.
5. Найдите параметр по названию, проверьте его идентификатор и текущие значения. Одноимённые параметры различаются по GUID/ID и типу данных.
6. Введите значение. Текст сохраняется как введён; числа интерпретируются в единицах проекта; для «Да/Нет» допустимы Да/Нет, 1/0, true/false. Очистка параметров в окне не предусмотрена.
7. Выберите «Заполнять только пустые значения» либо подтвердите перезапись. Числовой ноль и «Нет» считаются заполненными значениями. Предупреждение о перезаписи и отчёт относятся только к отмеченным строкам текущего фильтра.
8. После выполнения проверьте отчёт. Он содержит ID, исходные значения и результат для каждого элемента; строки можно скопировать через Ctrl+C. Чтобы отдельно заполнить хомуты, снова запустите команду на том же каркасе и выберите их семейство/тип.
9. Добавьте выбранный параметр в спецификацию и самостоятельно настройте фильтр.

Таблица первоначально отсортирована по семейству/типу и ID. Нажатие заголовка столбца меняет сортировку. Тип определяется по настоящему типу Revit; автоматическое распознавание формы по геометрии не выполняется. Для вложенных семейств список показывает семейство и типоразмер, для обычной арматуры — тип арматуры.

Если Revit не передал выделение строк спецификации как элементы, команда не обрабатывает всю спецификацию автоматически: используйте «Выделить в модели» и запустите её с плана/3D-вида.

Столбец «В наборе» показывает количество стержней в элементе Revit. Если выбранный `Rebar` или `RebarInSystem` содержит несколько стержней, параметр экземпляра принадлежит всему этому элементу. Команда не задаёт разные значения физическим позициям внутри одного набора и не отделяет их от него; предупреждение об этом показывается до записи.

## Недоступные параметры

Недоступность редактирования в интерфейсе и запрет записи через API отличаются. Команда использует запись через API для доступных параметров экземпляра. Параметры с `IsReadOnly`, формулами и управляющими связями не разблокируются принудительно; причины показываются в таблице. Семейства не редактируются и не перезагружаются.

Параметры типа не предлагаются: их изменение затронуло бы невыбранные экземпляры того же типа. Ссылочные параметры (материал, тип и другие ссылки `ElementId`) доступны только для просмотра. Отсутствующие параметры автоматически не создаются.

Для фильтрации на предоставленной модели кандидаты — «Марка спецификации», «Комментарии», «Арм.Группа ВРС». Окончательный параметр выбирает пользователь в окне. Нельзя считать доступным любой параметр, даже если его название похоже на один из этих примеров.

Операция объединена в один шаг отмены. После фиксации значения перечитываются; если Revit пересчитал их иначе, вся операция откатывается. Файлы проекта команда не сохраняет.

## Установка через EXE

Закройте Revit для обновляемых версий и запустите `TrueBIM-Setup-0.2.38.exe`.
На шаге выбора версий оставьте **Revit 2019**, если требуется только он.
Общий установщик содержит сборки для 2019–2026 и обновляет выбранные установки
TrueBIM текущего пользователя. Автоматическая установка в рамках проверки не выполнялась.

## Альтернативная установка ZIP-пакета для 2019

1. Распакуйте ZIP целиком и закройте Revit 2019.
2. Запустите `Install.ps1` из распакованной папки через PowerShell.
3. Запустите Revit 2019 и найдите команду в группе «КР» вкладки TrueBIM.

Пакет содержит полную сборку TrueBIM с новой командой и устанавливается только для текущего пользователя в 2019. Старые DLL сохраняются: новая сборка получает отдельную папку. Если `TrueBIM.addin` уже существует, сохраняется его копия; путь для возврата предыдущей версии выводится установщиком. Установки других версий Revit не изменяются.

Проверки и их ограничения перечислены в `VALIDATION.md`.
