# Ведомость отделки: полная площадь и принадлежность

## Статус проверки

Код выполнен в уже открытом пользователем **Revit 2023** на модели
`D085_П_АР_ALL_rvt23_тест_Отделки.rvt`. Проверка запускалась через локальный
граф Dynamo и отдельную сборку проверочного кода. Все изменения модели входили
во внешнюю группу транзакций и были отменены; исходный RVT не сохранялся.

Расчёт, запись параметров, создание нативных спецификаций, сохранение прежних
данных и повторный выпуск прошли проверку. В прогоне `live-07` нет ошибок,
зафиксирован успешный откат. **Визуальная проверка пока не завершена:** на
экспортированном листе обнаружено обрезание многострочных ячеек архивной
таблицы. Подготовлен следующий прогон `live-08`: нормализация переносов в ячейках,
проверка сохранения размещения на листе и уточнение верхней границы поиска
высокого потолка. Его запуск ожидает доступного рабочего стола Windows.
По запросу пользователя текущие изменения включены в установщик **0.2.16**.
Сборка установщика не заменяет эти две незавершённые проверки в Revit.

## Исправления расчёта

- Контакт выбирает помещение. Во всех категориях ведомость использует полную
  встроенную площадь элемента Revit (`HOST_AREA_COMPUTED`). Дверные ниши,
  высота помещения и размер пересечения больше не обрезают итоговую площадь.
- Каждый элемент учитывается один раз. При нескольких контактах выбирается
  наибольший; кандидаты и размеры контактов остаются в диагностике. При равных
  значениях выбор стабилен по ID помещения. Действительно общую отделку
  нескольких помещений необходимо проверить и при необходимости разделить
  в модели: автоматического распределения полной площади между комнатами нет.
- Стены сопоставляются с помещениями своего базового уровня, если на этом
  уровне есть валидные помещения. Отрицательное смещение основания стены
  верхнего этажа больше не переносит её принадлежность на нижний этаж.
- Для небольших откосов проверяется непрерывная цепочка соприкасающихся стен
  одного типа и уровня. Неопределённые участки получают помещение только тогда,
  когда все определённые соседи этой цепочки имеют одного владельца.
- Контур помещения проверяется на высоте отделки. Верхний предел поиска —
  основание следующего помещения выше, чья область в плане перекрывает текущую;
  помещение в другой части здания не ограничивает поиск. Если такого помещения
  выше нет, снят прежний предел
  «высота помещения плюс два метра». Для сложного контура перекрытия, на котором
  операция пересечения Revit завершается ошибкой, контакт дополнительно
  проверяется по точкам его поверхности. Это влияет только на принадлежность.
- Владельцы сначала определяются среди всех валидных помещений, затем
  применяется выбранная область отчёта. Принадлежность отделки других помещений
  не очищается; найденные по непрерывному контуру откосы включаются в запись.
- Принадлежность, параметры помещений и таблица используют один результат
  расчёта. Неопределённые элементы перечисляются в диагностике.

У потолка **2466464**, 400,998 м², типа с фасадной окраской, контакт с
помещениями в `live-07` не найден. Он явно присутствует в диагностике. По габаритам
он расположен над платформами; вероятная причина пропуска — прежний общий предел
по промежуточному уровню венткамеры 301 в другой части здания. Уточнённое ограничение
проверено модульными тестами, проверка на модели запланирована в `live-08`.

Один полный расчёт в прогоне `live-07` занял около **14,8 секунды** на текущей
машине. Это наблюдение для данной модели, а не гарантия времени на других проектах.

  включая помещение 211.

  принадлежности**. При сравнении учтено, что Revit нормализует переносы и
  удаляет внешние пробелы/пустые строки.

## Материалы проверки

В исключённом из Git каталоге `test-results/finish-model/live-07/` сохранены:
итог `report.json`, полный расчёт `report.json.audit.json`, проверки
`report.json.checks.json`, сравнение высот `report.json.heights.json`,
снимки текста старой ведомости до/после, перечень повторных изменений и PNG
временного листа. `LiveModelAudit.cs` обеспечивает откат; `FinishModelAudit.cs`
содержит проверки реальной модели и экспорт листа.

Вне Revit пройдены **179 модульных тестов** ведомостей отделки и спецификаций.
Перед сборкой 0.2.16 также пройден полный набор **1060 тестов** приложения,
без ошибок и пропусков.
Проверочная сборка с API Revit 2023 компилируется без ошибок; NU1900 сообщает
только о недоступности сетевой проверки уязвимостей NuGet.

Установщик **0.2.16** включает последнее уточнение верхней границы поиска.
Он рассчитан на Revit **2021–2026**. API Revit 2019/2020 на машине отсутствуют,
эти версии в пакет не включены. Высокий потолок и окончательный вид многострочных
ячеек требуют завершающей проверки в открытом Revit.
