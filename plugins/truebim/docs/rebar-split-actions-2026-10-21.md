# Разбить арматуру: извлечение из групп и закрепление — 0.2.42

Дата итоговой проверки: 22.10.2026. Нативная проверка копии пользовательской модели
в Revit 2022: **36/36**, включая **8 сценариев частичного выполнения с уведомлением**.

## Поведение

Для наборов внутри групп предлагаются два действия:

- «Извлечь из группы и разбить».
- «Пропустить обработку элементов».

Отмена, закрытие окна и Esc отменяют весь запуск. В окне доступны для копирования
ID наборов, их закрепление, название и ID группы. Соответствующие наборы других
экземпляров того же типа включаются в список до выбора действия.

При извлечении затронутые экземпляры и необходимые родительские группы
разгруппировываются через `Group.UngroupMembers()`. Новые группы не создаются.
Остальные элементы должны сохранить ID, геометрию, основу, закрепление и доступные
параметры. Незатронутые вложенные группы остаются группами. Эти условия проверяются
до фиксации и после неё. Если сохранить остальные элементы не удалось, попытка
откатывается, все обрабатываемые наборы внутри групп остаются без изменений,
а остальные наборы обрабатываются отдельно. Результат сообщает количество
необработанных наборов, их ID и причину. Новая попытка извлечения не выполняется.

Для оставшихся закреплённых наборов открывается отдельное окно: сохранить
закрепление новых стержней, снять закрепление, пропустить проблемные наборы
или отменить весь запуск. При пропуске сохраняются затронутые группы целиком,
чтобы не извлекать пропущенный набор ради другого выбранного набора.

Вариант с сохранением общего типа и ID групп исключён из выпуска по уточнению
заказчика от 22.10.2026. Прежние тесты этого варианта не подтверждают новую реализацию.

## Геометрия и оформление

Сохраняются геометрия каждой существующей позиции, тип, основа, крюки, доступные
параметры и выбранное закрепление. Исключённые позиции не создаются заново.
В Revit 2022+ учитываются индивидуальные перемещения стержней.

Опция «Сохранять аннотации» переносит поддерживаемые независимые марки,
линейные размеры и мультиарматурные аннотации на прежних видах. Проверяются
геометрическое соответствие ссылок, значения и сегменты размеров.
При выключенной опции оформление, сохранённое самим Revit, не удаляется принудительно.

Присоединённые группы узлов не сохраняются как группы. Неподдерживаемое или
невосстановимое оформление может быть потеряно; результат перечисляет ID и причины.
Штатные предупреждения Revit не подавляются. Успешный запуск отменяется одним Undo.

## Результат на пользовательской модели

На копии `Тест_rvt22.rvt`:

- Выбор всех 9 наборов с извлечением: получено 45 отдельных стержней;
  проверены геометрия, выбранное закрепление и перенос обычных размеров.
- Охват «Все наборы переменных стержней»: обработаны 2 набора, создано 10 стержней.
  Наборы **2030788 и 2030863** пропущены, поскольку Revit меняет форму позиции 2
  соседнего набора **2030862** при разгруппировании. Наборы и группы сохранены
  без изменений, ID и причина есть в итоговом сообщении плагина.
- Это ограничение проверено с сохранением и снятием закрепления, с включёнными
  и выключенными аннотациями, на исходном виде и виде размеров — 8 сценариев.
- Отмена, явный пропуск и отдельный выбор обычной арматуры также прошли проверки.

Отчёт: `test-results/rebar-split/revit-2022-e7163ff6eee44630a1618b73334274f9.json`.
Для автоматически пропущенных источников и оставленных размеров проверяется
неизменность `VersionGuid`. Для обработанных — число стержней, геометрия,
основа, закрепление, удаление исходников и ссылки/оформление линейных размеров.

## Остальные проверки и границы подтверждения

- Итоговые модульные тесты: **1175/1175**,
  `test-results/rebar-split/release-0.2.42/extract-groups-final.trx`.
- Включены проверки двух вариантов для групп, трёх действий для закрепления,
  доступности кнопок, копируемого списка ID и безопасного значения по умолчанию.
- Полный нативный стенд содержит 176 сценариев: обычная и закреплённая арматура,
  повторяющиеся, вложенные, повёрнутые и зеркальные группы; крюки, изгибы,
  переменная длина, исключённые и перемещённые позиции; ошибки параметров;
  марки, МРА и линейные размеры; независимый выбор для групп и закрепления;
  замеры извлечения из 10 и 100 экземпляров.
- Проверка копии пользовательской модели содержит 36 сценариев: два охвата,
  действия с группами и закреплением, оба состояния галочки аннотаций,
  исходный вид и вид размещения размеров.
- Полный синтетический прогон 176 сценариев для итоговой реализации не подтверждён.
  Попытка объединить его с моделью была непригодна: 82 ошибки создания фикстур
  в неактивном документе. Режимы снова запускаются раздельно. После ограничения
  заказчика двумя запусками выполнены только два прогона пользовательской модели;
  дальнейших запусков Revit не было. Результаты старого алгоритма групп не выдаются
  за проверку текущего.

Нативные проверки запускаются в отдельном Revit Viewer. Все операции откатываются;
исходная модель и установленный TrueBIM не изменяются.

## Общий установщик

Пакет предназначен для Revit 2019–2026 и включает все текущие команды,
компактную ленту и изменения «Цветов по параметрам». Для всех восьми сборок
проверяются исходники через контрольные суммы в PDB, три дополнительных модуля
и отсутствие Revit API DLL в комплекте. Нативная проверка относится к Revit 2022.
Установка на компьютер пользователя не выполняется автоматически.
