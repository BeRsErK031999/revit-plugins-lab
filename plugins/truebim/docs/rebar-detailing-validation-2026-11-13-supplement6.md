# Вертикальные сечения — Дополнение 6

Источник: пользовательский архив `Дополнение 6.rar`, документ `Дополнение 6.docx`
и модель `D114_Р_КР_КЖ04.2.1_rvt24.rvt`. В документе замечания с 22 иллюстрациями;
эталоны расположены на листе «Для правок». Исходные DOCX/RVT, извлечённые изображения
и результаты прогонов находятся в игнорируемом `tmp/vertical-detailing/`.

SHA-256 исходной RVT: `F1F4C65A93F0295AF8F6EE91F50635746B2D536B55B51D9925489DEF2ABF4DD3`.

## Изменения

| Замечание | Реализация |
| --- | --- |
| Арматура связи меняет вариант и получает марки | Связанная арматура исключается при сборе геометрии. Она не участвует в варианте, размерах, марках, шпильках и габаритах обрывов. Бетон связей продолжает читаться. |
| Лишние размер толщины и отметка низа нижней плиты | Из размерных и высотных цепочек исключаются отдельные группы нижних опорных конструкций. Сохраняются привязки стены и верхняя поверхность её опоры. |
| Автоматический вынос тесного размерного текста | Раскладка использует ширину шрифта, высоту и коэффициент сжатия выбранного типа. |
| Нижние размерные подписи | Помещающийся текст остаётся по центру, крайние тесные подписи выносятся наружу к выносным линиям, промежуточные — в отдельный ряд. |
| Боковые размерные подписи | Нижняя крайняя привязка выносится вниз, верхняя — вверх; помещающийся размер бетона остаётся между линиями. |
| Недоступная привязка высотной отметки | После неудачной попытки по грани создаётся линия детализации длиной 1 мм со стилем `Линия_высотная`. Участок проверяется по реальной грани, включая отверстия; линия должна находиться между обрывами. |
| Минимум A шпильки | `max(160 мм, толщина стены − 50 мм)`. |
| Нижний конец обрыва | Свободные вертикальные концы нижнего обрыва плиты продлеваются на 80 мм; учитываются видимые линии семейства. |
| Двойной размер нижней стены связи | Связанная арматура больше не создаёт отдельную оформляемую группу этой стены. |
| Привязки к разным сторонам арматуры | Для поперечных стержней выбирается левая доступная ось; правые точечные оси исключаются из левой цепочки. |
| Марка массива и сохранение настроек | Марка единственного массива располагается у соответствующей формулы шага, в том числе при коротком крайнем интервале. Галочки, типы, вариант и тексты выносок сохраняются в памяти до закрытия Revit. Отмена окна не заменяет последнее применение. |

Опорная линия отметки имеет собственную метку команды. Она удаляется вместе
с заменяемыми отметками, сохраняется при выключенных отметках и откатывается
вместе с видом. Ручные линии того же стиля не считаются собственными.
Числа размеров и отметок остаются измеряемыми значениями Revit.

На нативной проверке выявлено ограничение семейства углового обрыва:
комбинация плеч 464,098/300 мм не строится, а обратное назначение строится.
Для этого семейства короткое плечо назначается первой линии, ориентация
и отражение выбираются по контуру. Угол и свободные концы сохраняют положение.

## Автоматические проверки

- Модульные тесты: **1302/1302**, без ошибок и пропусков.
  `tmp/vertical-detailing/supplement6/tests/supplement6-final.trx`.
- API Revit **2019** и **2024**, `net48`: сборки без ошибок и предупреждений.
  Для 2019 использованы локальные reference assemblies; это не запуск Revit 2019.
- API Revit **2025**, `net8.0-windows`: сборка в составе запуска тестов.
- Добавлены сценарии для минимума шпильки, нижних и боковых тесных привязок,
  сохранения помещающегося текста по центру и обхода формулы шага.
- Нативный стенд дополнен принудительной проверкой опорной линии 1 мм,
  её принадлежности переключателю отметок, замены и полного отката,
  измерением отступа 80 мм по видимым линиям семейства и проверкой настроек окна.
- Стили с нулевой высотой текста (только засечки) исключены из расчёта ширины:
  на исходной модели такой стиль вызывал ошибку `emSize` при первом прогоне.

## Проверка модели

Проверка выполняется в отдельном Revit 2024.3 на отсоединённой копии.
В архиве нет файлов связей. Для доступных связей `КЖ03.2.1` и `ALL`
использованы локальные тестовые модели из предыдущих дополнений; их соответствие
актуальной модели автора не подтверждено. Остальные отсутствующие связи не загружаются.

При открытии обнаружены некорректные ссылки существующих размеров и отметок до запуска
команды. Их восстановление/удаление выполняется только в тестовой копии;
проверка сохранности геометрии и повторного оформления начинается после открытия.

Нативная приёмка завершена успешно:
`tmp/vertical-detailing/native/7167e351c1d341eb8aeb1bf92d79cf04/report.json`.

- «Узел 38», «Узел 43» и «Узел 49»: первое и повторное оформление успешны;
  аннотации и обрезка стабильны при повторе, геометрия модели сохранена.
- Пакетное оформление, откат, отключённые опции, ручные подписи и текстовые
  комментарии прошли проверки. Все проверки дополнений 4–6 успешны.
- На каждом узле принудительно проверена отметка по опорной линии 1 мм,
  сохранение линии при выключенных отметках, замена и откат.
- По видимым линиям нижних обрывов измерено **80,000 мм** до низа плиты.
- Все **8** сочетаний угла и длины плеч строятся; проверены положение,
  длины и направления плеч с учётом отражения семейства.
- В настоящем окне Revit проверены применение настроек, восстановление при
  повторном открытии, сохранение после отмены изменений и восстановление
  начальных значений после очистки памяти сессии. Сброс проверен очисткой
  статических полей; отдельный сценарий закрытия и повторного запуска Revit
  для этой проверки не выполнялся.
- Окно и методичка отрисованы. Изображения трёх оформленных узлов и угловых
  обрывов просмотрены. Хеши исходных файлов не изменились.
