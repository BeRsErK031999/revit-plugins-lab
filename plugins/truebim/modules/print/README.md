# Печать

Модуль пакетной печати и экспорта листов Revit в PDF, DWG и DXF.

Статус: первый рабочий релиз остается release candidate для Revit 2022 и Revit 2025. Пользовательские замечания, подтверждение по логу и этапы исправлений собраны в [`docs/print-feedback-roadmap.md`](../../docs/print-feedback-roadmap.md); первый этап оптимизации выполнен в коде и ожидает ручной проверки в Revit.

## Что сделано

- Кнопка `Печать`, Revit-команда, manifest и подключение к launcher.
- Единое окно для PDF, DWG, DXF и DWF: `PDF + Один PDF` объединяет листы документа в PDF; `DWG + Целый лист DWG` сохраняет каждый лист вместе с его видами в отдельный DWG. Подробные параметры раскрываются кнопкой `Настройки...`.
- Локальные именованные пресеты для заказчиков с сохранением папки, маски, форматов, PDF-параметров, CAD setups и DWG-профиля.
- Окно выбора листов из открытых документов Revit.
- Фильтр источника и сохранение выбора листов при переключении источников.
- Конструктор имени файла с предпросмотром, нормализацией и русскими токенами `{Номер листа}`, `{Имя листа}`, `{Номер проекта}`, `{Имя проекта}`, `{Имя документа}`, `{Дата:yyyy-MM-dd}`, `{Счетчик}` и `{Счетчик:000}`. Старые английские токены также поддерживаются для сохраненных настроек.
- Прямой экспорт отдельных PDF через `PDFExportOptions`.
- Объединенный PDF через один вызов `Document.Export` на документ-источник.
- PDF-настройки цвета, качества растровых элементов и raster/vector режима.
- Прямой экспорт DWG и DXF.
- Выбор DWG/DXF export setup из сохраненных настроек Revit.
- Расширенный DWG-профиль поверх `DWGExportOptions`: версия DWG, цвета, переопределения, единицы, координаты, внешние ссылки, solids, линии, штриховки, текст и базовые layer/file mappings.
- Fallback на стандартные `DWGExportOptions` / `DXFExportOptions`, если setup не выбран или в документе нет сохраненных CAD setups.
- Сохранение базовых настроек окна в `%APPDATA%\TrueBIM\<RevitVersion>\print-settings.json`.
- Сохранение DWG-профилей в `%APPDATA%\TrueBIM\<RevitVersion>\dwg-export-profiles.json`.
- Сохранение пресетов печати в `%APPDATA%\TrueBIM\<RevitVersion>\print-presets.json`.
- Сохраняемая опция `Открыть папку`: после завершения пакетного экспорта Проводник открывается один раз, только если создан хотя бы один файл.
- Итоговый отчет по фактическим результатам экспорта: первые три полных пути видны сразу, полный список файлов и ошибок доступен в подробностях.
- Unit-тесты чистой логики печати.

Если в Revit открыто несколько документов, модуль собирает листы из каждого документа с печатаемыми листами. В окне есть фильтр источника; выбор листов сохраняется при переключении фильтра и восстанавливается при возврате к источнику. При экспорте каждый лист отправляется через свой `Document`. Для режима `Один PDF` при выборе листов из нескольких документов создается отдельный объединенный PDF на каждый документ.

Флаг `PDF` включает формат, а `Один PDF` переключает результат с отдельных файлов на один файл для каждого документа-источника. В объединенном режиме модуль экспортирует выбранные листы одним вызовом `Document.Export`, нормализует имя общего файла и не блокирует PDF-only экспорт из-за дублей индивидуальных имен листов. Также доступны настройки цвета, качества растровых элементов и raster/vector режима.

Для DWG и DXF окно показывает отдельные настройки экспорта. Если в документе нет сохраненных CAD export setups или пользователь оставляет значение по умолчанию, модуль экспортирует через стандартные `DWGExportOptions` / `DXFExportOptions` и отображает fallback в статусе. Для DWG доступно окно `Настройки DWG...`: профиль может использовать Revit Export Setup как базу, поверх нее применяет выбранные `DWGExportOptions`, сохраняется в JSON и может создать новый Revit DWG Export Setup без изменения глобальных настроек без явного действия пользователя.

### Целый лист DWG — исправление от 02.10.2026

Включите `DWG` и оставьте включенной галочку `Целый лист DWG`: каждый выбранный лист экспортируется отдельным вызовом Revit и получает имя по общей маске листов. Виды, легенды и связи не выносятся в отдельные DWG. Если снять галочку, виды и связи экспортируются как внешние ссылки (XRef). Настройка сохраняется в последнем состоянии и именованных пресетах.

Раньше `Один DWG` отправлял все листы одним вызовом и устанавливал `DWGExportOptions.MergedViews = true`. Этот параметр включает внешние ссылки, а не объединение нескольких листов в один чертёж. Это соответствует [описанию Autodesk](https://blog.autodesk.io/api-access-to-export-views-on-sheets-and-links-as-external-references-settings-in-exporting-revit-fi/) и [настройкам экспорта DWG](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-DocumentPresent/files/GUID-A170C41E-7C8A-4D7D-A552-FBFB4BD604A0.htm). Для целого листа теперь применяется `MergedViews = false`, включая профили и сохранённые Revit setups с включёнными XRef. Исходный профиль не изменяется. Маска общего DWG убрана из окна; проверка существующих файлов, прогресс и отчёт используют отдельные листы. В отчёт успешного CAD-экспорта попадают только существующие выходные файлы.

Новое поле `keepDwgSheetsWhole` по умолчанию равно `true`, в том числе при чтении старых настроек и пресетов. Старые поля `combineDwg` и `combinedDwgFileNameMask` читаются для совместимости, но больше не управляют именами или группировкой экспорта. В расширенном профиле галочка `Виды и связи отдельными DWG (XRef)` обратна галочке целого листа в основном окне.

Растровые изображения могут оставаться отдельными файлами: это [ограничение DWG, описанное Autodesk](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Is-it-possible-to-export-to-DWG-file-without-images-as-references-from-Revit.html).

Автоматическая проверка: 119 тестов модуля печати, включая миграцию настроек/пресетов, приоритет галочки над профилем и счётчик отдельных DWG. Ручная проверка в Revit ещё требуется: экспортировать два листа с несколькими видами и легендой в пустую папку, проверить два основных DWG и отсутствие DWG внешних ссылок, затем повторить со снятой галочкой. Также проверить `Пропустить`/`Заменить` для существующих файлов и сохранение выбора после повторного открытия окна.

Последнее состояние окна сохраняется в `%APPDATA%\TrueBIM\<RevitVersion>\print-settings.json`. Именованные шаблоны заказчиков сохраняются отдельно в `%APPDATA%\TrueBIM\<RevitVersion>\print-presets.json`; каждый пресет содержит папку экспорта, маску имени, флаги форматов/объединения, опцию открытия папки после успешного экспорта, параметры PDF, CAD setups и снимок DWG-профиля. Старое поле `отдельные + общий PDF` при чтении сворачивается в `Один PDF`. Расширенные DWG-профили также остаются доступны в `%APPDATA%\TrueBIM\<RevitVersion>\dwg-export-profiles.json`.

## Завершенные задачи первого релиза

1. Каркас кнопки и модуля.
2. MVP окна печати.
3. Конструктор имени файла.
4. PDF export: отдельные файлы, объединенный PDF и PDF-настройки.
5. DWG/DXF export: прямой экспорт, выбор Revit export setup, расширенный DWG-профиль и default fallback.
6. Несколько источников листов: открытые документы, фильтр источника и сохранение выбора.
7. Сохранение базовой конфигурации окна.
8. Unit-тесты, Release build/test, local deploy и installer preflight.
9. Единый вход `Печать` и локальные именованные пресеты заказчиков.
