# Свернуть ВРС

Модуль изменяет выбранную спецификацию Revit только в полях, имена которых начинаются с `Р • ИА…` или `Р • ИЗ…`: показывает числовые столбцы с ненулевыми значениями и скрывает нулевые или пустые. Видимость остальных полей сохраняется, даже если в них есть числа.

## Рабочий сценарий

1. Если исходную спецификацию нужно сохранить без изменений, заранее сделать ее копию в Revit.
2. Открыть TrueBIM и запустить `Свернуть ВРС`.
3. В окне выбора источника указать один из вариантов: активное окно, выбранная спецификация в диспетчере проекта или выбор из списка с поиском.
4. Если выбран список, указать спецификацию, которую нужно свернуть.
5. Получить ту же спецификацию: в полях `Р • ИА…` и `Р • ИЗ…` ненулевые столбцы показаны, нулевые числовые столбцы скрыты.

## Правила безопасности

- Выбранная спецификация изменяется напрямую.
- Изменения выполняются в одной транзакции Revit.
- Поля выбираются по имени параметра/вычисляемого поля, а не по переименованному заголовку колонки. Пробельные и неразрывные пробелы вокруг `•` поддержаны; префикс с дефисом `Р - ИА` не входит в обработку.
- Проверяются также скрытые числовые поля с указанными префиксами.
- Текстовые поля, включая текстовые коды из цифр, сохраняют исходную видимость.
- Поля фильтрации, сортировки и группировки сохраняют исходную видимость, в том числе числовые служебные поля.
- Итоговые числовые колонки с указанными префиксами скрываются, если все их значения равны нулю, и показываются при наличии ненулевых значений. Иные итоги сохраняют свою видимость.
- Пустые числовые колонки также скрываются: нули могут быть подавлены настройками отображения Revit. Пустыми считаются пустые строки, пробелы и отдельные прочерки.
- Тип числового поля и значения с единицами измерения определяются через Revit API с учётом формата поля.
- Если в числовой колонке нет подтверждённых ненулевых значений, но есть нераспознанные значения (например, `<Различные>`), исходная видимость сохраняется.
- Повторный запуск из скрытого или раскрытого состояния приводит к одной видимости числовых колонок с читаемыми значениями. Текстовые и служебные поля в этот пересчёт не входят.
- Многострочная шапка, в том числе ГОСТ, класс стали и числовые заголовки `-10` и `-12`, исключается из чтения средствами Revit. Число в строке данных учитывается даже при совпадении с заголовком.
- Временное раскрытие целевых полей и отключение шапки для чтения откатываются до применения результата. Оформление шапки сохраняется; неопределённые поля не остаются раскрытыми.
