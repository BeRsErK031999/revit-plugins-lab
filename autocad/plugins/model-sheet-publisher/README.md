# Model Sheet Publisher 0.2.0

Продукт направления [AutoCAD](../../README.md). Путь в репозитории: `autocad/plugins/model-sheet-publisher/`. Скрипт `build.ps1` создаёт новые пакеты в `autocad/dist/`.

Печать выбранных листов **из модели AutoCAD 2021–2026** в один многостраничный PDF или отдельные PDF. Запуск: вкладка ленты **Печать PDF → Листы в PDF**. Также доступна команда **MSPUBLISH**. Единый пакет для полного AutoCAD 2021–2026 x64 под Windows. AutoCAD LT и macOS не поддерживаются. Запуск в AutoCAD проверен на версии 2021; для 2022–2026 выполнены проверки компиляции по API, а для современной ветки — отдельные проверки PDF и окон под .NET 8/10. Подробности в `VALIDATION.md`.

## Установка

1. Закройте все версии AutoCAD и распакуйте весь ZIP в папку с коротким путём, например `C:\Tools\ModelSheetPublisher`.
2. Запустите `Install.cmd`. Он копирует `ModelSheetPublisher.bundle` в `%APPDATA%\Autodesk\ApplicationPlugins`. Права администратора не нужны. Существующая версия обновляется; её резервная копия сохраняется в `%LOCALAPPDATA%\ModelSheetPublisher\Backups`.
3. Откройте нужную версию AutoCAD 2021–2026. При первом запуске AutoCAD может показать окно **«Исполняемый файл без подписи»** для `ModelSheetPublisher.dll`: разрешите загрузку этой сборки, если устанавливаете данный пакет.
4. Нажмите **Печать PDF → Листы в PDF** на ленте. Если лента скрыта, включите её командой `RIBBON`.

Для разовой проверки без установки: команда `NETLOAD`, файл `ModelSheetPublisher.bundle\Contents\Windows\net48\ModelSheetPublisher.dll` для 2021–2024 или `ModelSheetPublisher.bundle\Contents\Windows\net8.0-windows\ModelSheetPublisher.dll` для 2025–2026, затем `MSPUBLISH`. Остальные DLL должны оставаться рядом. AutoCAD может запросить разрешение загрузить неподписанную сборку. Не отключайте `SECURELOAD` глобально; при необходимости добавьте выбранную папку плагина в доверенные расположения AutoCAD.

Чтобы удалить плагин, закройте AutoCAD и удалите только папку `%APPDATA%\Autodesk\ApplicationPlugins\ModelSheetPublisher.bundle`.

## Один пакет для шести версий

Установщик один раз размещает пакет в пользовательской папке ApplicationPlugins. Можно иметь несколько версий AutoCAD на одном компьютере: каждая автоматически загружает только подходящий модуль.

| AutoCAD | Диапазон API | Модуль |
|---|---|---|
| 2021, 2022, 2023, 2024 | R24.0–R24.3 | net48 — .NET Framework 4.8 |
| 2025, 2026 | R25.0–R25.1 | net8.0-windows — .NET 8 |

Сборка net8 также предназначена для обновлений AutoCAD 2025.1.4 и 2026.1.2, в которых Autodesk перешёл на .NET 10. Зависимости PDF и окна проверены под .NET 10 отдельно от AutoCAD; нативная печать именно в этих обновлениях здесь не проверялась. Сам AutoCAD и его .NET-компоненты этот установщик не устанавливает и не обновляет.

При обновлении с 0.1.0/0.1.1 старый пакет целиком переносится в резервную копию: DLL разных выпусков не смешиваются. Перед изменением установленного пакета проверяется комплектность обеих сборок и контрольные суммы. Интернет при установке не нужен.

## Порядок работы

1. В списке сверху выберите открытый DWG. Кнопка **Открыть DWG…** позволяет открыть ещё несколько файлов для выбора листов; они открываются только для чтения.
2. Нажмите **Листы щелчками**. Щёлкните **по линии внешней рамки**: один щелчок сразу добавляет лист. Выбранная область подсвечивается до возврата в окно. В пустом месте внутри листа выбирать нечего — нужна граница или объект блока. Поддерживаются замкнутые прямоугольные полилинии, рамки из отрезков и рамки внутри блоков. Повторное добавление той же области не создаёт дубликат.
3. Для произвольной области используйте **Области по 2 углам**. Каждый прямоугольник становится отдельной страницей.
4. `Enter` или `Esc` возвращает в окно. Уже добавленные листы остаются в очереди.
5. Выделите строки, в том числе несколько через Ctrl/Shift. **Выше / Ниже** меняют порядок. Двойной щелчок или **Параметры листов…** открывает формат, ориентацию, масштаб, поля, центрирование и смещение.
6. Выберите PDF-плоттер, таблицу CTB/STB, толщины линий и прозрачность. Для чёрно-белой печати обычно выбирают установленную `monochrome.ctb`; тип таблицы должен соответствовать DWG. Качество и разрешение задаются профилем PC3, например `AutoCAD PDF (High Quality Print).pc3`.
7. Проверьте выбранный лист кнопкой **Предпросмотр листа**. Создаётся временный PDF и открывается в установленном просмотрщике.
8. Нажмите **Создать PDF**: откроется отдельное окно для имени, папки и режима общего/отдельных PDF. В нём показаны будущие имена файлов. Настроить имя заранее можно кнопкой **Имя PDF…**; расширение `.pdf` допускается и не дублируется.

Начальное имя берётся из текущего DWG. Отдельные файлы называются `Имя_001.pdf`, `Имя_002.pdf` и так далее в порядке строк очереди. При совпадении имён подтвердите замену. Все страницы сначала готовятся во временной папке, затем заменяются итоговые файлы. При отмене прежние PDF остаются; при ошибке замены выполняется откат. Если PDF открыт с блокировкой, закройте его в просмотрщике и повторите печать. При невозможности отката сообщение укажет папку с резервными копиями.

Кнопки **Сохранить очередь / Загрузить очередь** работают с файлами `.mspqueue`. Сохраняются пути DWG, области, порядок и параметры печати. Геометрия DWG в очередь не копируется: после изменения чертежа следует проверить подборку заново. Открытые чертежи печатаются с текущими изменениями в памяти, закрытые — с диска.

## Форматы и масштаб

- A4, A3, A2, A1, A0, A4×3…A4×9, A3×3…A3×7, A2×3…A2×5, A1×3…A1×4, A0×2…A0×3.
- Нестандартные размеры от 10 до 5080 мм по каждой стороне.
- Автоматический подбор учитывает размер, пропорции и единицы модели. Геометрия сама по себе не всегда определяет физический формат: например, одинаковое соотношение сторон возможно у разных A-форматов. Для увеличенных ISO-рамок при неоднозначности предпочтён масштаб около 1:100. Проверьте показанный размер, особенно если выбрана внутренняя рамка со штампом.
- **Вписать** сохраняет пропорции и учитывает заданные поля. **Точный масштаб** задаёт отношение «миллиметры бумаги = единицы модели», например `1 мм = 100 ед.`.
- При выключенном вписывании содержимое за границей печатной области обрезается. При выключенном центрировании начало отсчитывается от нижнего левого угла с учётом полей и смещения X/Y.
- Размер PDF не ограничен списком стандартной бумаги PC3: длинный лист собирается из векторных участков с тем же масштабом. Плагин не преобразует весь чертёж в растровую картинку. Содержимое, которое сам AutoCAD печатает растром, остаётся растровым.

## Ограничения

- Автоматическое распознавание рассчитано на прямоугольники, параллельные мировым осям X/Y, в виде сверху. Для повёрнутых, незамкнутых, нестандартных и прокси-рамок задайте область вручную. Рамки из внешних ссылок автоматически не обходятся; их содержимое печатается AutoCAD в выбранной области.
- Сложная геометрия может содержать другие прямоугольники. После добавления проверяйте формат и предпросмотр. Для полилинии используется выбранная прямоугольная граница; для отрезков — наибольшая замкнутая рамка, которой принадлежит выбранный отрезок; для блока — внешняя рамка в месте щелчка.
- Не воспроизводятся все вкладки стандартного диалога PLOT. Основные параметры доступны в окне плагина, качество задаётся PC3, остальные исходные параметры наследуются от настроек модели.
- Для точного вида PDF нужны исходные SHX/TTF, таблицы CTB/STB и внешние ссылки. В предоставленном примере отсутствовали некоторые локальные шрифты ГОСТ/СПДС, и AutoCAD подставлял `simplex.shx`.
- Формат PDF сохраняет графическое содержимое; интерактивные ссылки и комментарии промежуточного PDF-плоттера не переносятся при сборке векторных участков.
- Отмена применяется после текущего участка печати. Готовые пользовательские PDF появляются только после успешной обработки всей очереди. Плагин не сохраняет исходные DWG.
- Автоматически открытые для фоновой печати файлы закрываются без сохранения. Файлы, открытые пользователем для выбора, остаются открытыми. Предпросмотры находятся в `%TEMP%\ModelSheetPublisher`.

## Разработка и проверка

Исходный код находится в `src`, проверки расчётов и очереди — в `tests`, проверка компоновки окон — в `tests-ui`. Скрипт `build.ps1` собирает ZIP. Для сборки нужны Windows, .NET SDK 8 и доступ к NuGet. Библиотеки API загружаются из официальных пакетов Autodesk `AutoCAD.NET` и используются только при компиляции. Установленный AutoCAD для сборки не требуется.

При упаковке диагностические команды исключаются. В сборке для разработки `MSPDIAG` читает состав чертежа, `MSPSMOKE` проверяет несколько листов, `MSPFIXTURE` создаёт отдельный тестовый DWG, `MSPSUITE` проверяет печать 200 страниц. Эти команды работают с временными результатами и предназначены для разработчика.

Подробные результаты — в `VALIDATION.md`. Основа совместимости: [таблица Autodesk для AutoCAD и .NET](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Customization/files/GUID-A6C680F2-DE2E-418A-A182-E4884073338A.htm); печать использует штатные [PlotSettings и PlotEngine](https://help.autodesk.com/cloudhelp/2015/ENU/AutoCAD-NET/files/GUID-CE91C625-A278-4445-8219-3A2D880E6C22.htm).
