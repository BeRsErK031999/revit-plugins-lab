## Границы подтверждённой совместимости

На компьютере установлен **только AutoCAD 2021 R24.0.47.0**. Запуск внутри AutoCAD 2022, 2023, 2024, 2025 и 2026 здесь не выполнялся. Компиляция по их API, проверка маршрутизации загрузчика и отдельный запуск PDF/WinForms не заменяют нативную проверку плоттера, ленты и переключения DWG в каждом выпуске.

Для поставки использованы API 2021 (`AutoCAD.NET 24.0.0`) и API 2025 (`AutoCAD.NET 25.0.1`); остальные SDK применялись для проверки исходного кода. Согласно [таблице совместимости Autodesk](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Customization/files/GUID-A6C680F2-DE2E-418A-A182-E4884073338A.htm), AutoCAD 2022–2024 поддерживает SDK 2021, AutoCAD 2026 — SDK 2025. Диапазоны `R24.0–R24.3` и `R25.0–R25.1` не пересекаются.

AutoCAD 2025.1.4 / 2026.1.2 перешли на .NET 10. Для совместимости с ранними обновлениями современный модуль оставлен с целью net8. Autodesk [указывает ожидаемую совместимость приложений net8 с новым runtime](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-ReleaseNotes/files/autocad_2025_updates/AUTOCAD_2025_1_4_FIXED_ISSUES.html). Его собственные операции PDF и окна дополнительно проверены под .NET 10; нативный AutoCAD с этими обновлениями не запускался.

Сборки не имеют цифровой подписи. AutoCAD может запросить разрешение загрузки. Поддержка LT/macOS не заявляется. Требования к исходным шрифтам, CTB/STB, внешним ссылкам и осевым прямоугольным рамкам остаются прежними.

## Воспроизведение и артефакты

- `build.ps1`: сборка обеих веток, расчёты/очередь, проверка комплекта, итоговый ZIP. Autodesk SDK загружается из NuGet; для сборки установленный AutoCAD не требуется.
- `tests-package/Test-SdkMatrix.ps1`: проверка API всех шести выпусков. Локальные журналы: `tmp/model-sheet-publisher/sdk-matrix-020`.
- `tests-package/Test-Install.ps1 -PackageRoot <распакованный пакет>`: установка/обновление в отдельной папке. Локальный результат: `tmp/model-sheet-publisher/install-check-020/PASS.txt`.
- Реальное обновление 0.1.1 в Windows PowerShell 5.1: `%TEMP%/msp-upgrade020-winps5/PASS.txt`.
- `tests-runtime/RuntimeCheck.csproj`: сборка net48/net8.0-windows, запуск с папкой вывода; для .NET 10 — `dotnet --roll-forward Major RuntimeCheck.dll <папка>`. Результаты: `tmp/model-sheet-publisher/runtime-check-net48`, `runtime-check-net8`, `runtime-check-net10`.
- Нативная проверка устанавливаемого модуля: `%TEMP%/msp-revision-20261102-163339/PASS.txt` содержит версию 0.2.0.0 и путь загруженной DLL. Команды `tests-host` не включаются в ZIP.

## Что выявлено и исправлено

- В консольном AutoCAD часть API открытия/закрытия документов из AcMgd недоступна. Эти вызовы отделены; многодокументный сценарий проверен в полном AutoCAD.
- В AutoCAD не применяются app.config-перенаправления зависимостей отдельного плагина. Добавлен ограниченный загрузчик поставляемых зависимостей PDFsharp.
- При сильном отдалении видимого чертежа выбор рядом с внутренней линией мог предпочесть ячейку штампа внешней рамке. Теперь сначала выбирается внешняя рамка, содержащая точку. Исправление проверено на А2 из предоставленного файла.
- Для модели без сохранённого окна печати область должна задаваться до установки типа Window. Проверено на новом синтетическом DWG.
- Открытие второго DWG нельзя выполнять из обработчика модального окна. Печать выполняется в контексте Session-команды с отдельным немодальным окном прогресса.

## Практические границы проверки

- В примере не были доступны некоторые SHX/TTF ГОСТ/СПДС. Подстановка шрифтов видна в журнале AutoCAD; точность исходной типографики здесь не подтверждена.
- Физические принтеры, AutoCAD LT, другие версии AutoCAD, повёрнутые непрямоугольные рамки и разные наборы сторонних надстроек не проверялись.
- Все варианты масштаба/размещения проверены расчётами; визуальные проверки выполнены для представительных страниц, а не для всех 200 страниц вручную.
- Исходный файл пользователя не сохранялся плагином. Зафиксированный SHA-256 исходного DWG: `51EDA3D5BACBF153D4B4F318D8EEF7BE9F9CA6DDE542FF7D1C3C240E927622E2`.

## Воспроизведение

Расчёты: `dotnet run --project tests/ModelSheetPublisher.Tests.csproj -c Release`.

Консольные проверки: сборка проекта `src`, загрузка DLL через NETLOAD в AutoCAD 2021 Core Console; `MSPFIXTURE` создаёт `%TEMP%\msp-fixture.dwg`. В отдельном процессе с этим DWG команда `MSPSUITE` создаёт `%TEMP%\msp-suite-<дата-время>` с PDF, журналами и PASS/FAIL. `MSPSMOKE` работает на предоставленном примере.

Полный AutoCAD: `tests-host` содержит команды для проверки нескольких DWG, выбора и окна прогресса. В версии 0.1.1 `MSPSELECTCHECK` выбирает объект внешней рамки копии предоставленного DWG: `1694455,783675.931`, пустой ввод, `1664755,841886.957`, `1706755,871586.957`, пустой ввод. Тест временно задаёт UCS со смещением (100, 200) и восстанавливает её.

Диагностические команды и тестовые сборки не включены в устанавливаемый пакет.
