# AutoCAD

Отдельное направление репозитория для плагинов и автоматизации AutoCAD. Все дальнейшие задачи AutoCAD — разработка, работа с API, печать, совместимость и установщики — ведутся здесь.

## Структура

```text
autocad/
  AGENTS.md                       инструкции для дальнейшей работы
  plugins/
    model-sheet-publisher/        печать листов из пространства модели
  dist/                           готовые пакеты, локально, вне Git
  tmp/                            тестовые файлы и журналы, вне Git
```

## Продукты

| Продукт | Версия | Назначение | Целевые версии |
|---|---|---|---|
| [Model Sheet Publisher](plugins/model-sheet-publisher/README.md) | 0.2.0 | Выбор рамок в модели, настройка форматов и порядка, общий или отдельные PDF | AutoCAD 2021–2026, Windows x64 |

У плагина есть кнопка **Печать PDF → Листы в PDF** и команда `MSPUBLISH`. Единый установщик выбирает подходящую сборку автоматически.

**Подтверждённая проверка:** реальный запуск в AutoCAD 2021; компиляция по API всех шести выпусков; отдельные проверки PDF и окон под .NET Framework, .NET 8 и .NET 10. AutoCAD 2022–2026 на тестовом компьютере не запускался. Полные результаты — в [VALIDATION.md](plugins/model-sheet-publisher/VALIDATION.md).

## Сборка

Из корня репозитория в PowerShell:

```powershell
& ./autocad/plugins/model-sheet-publisher/build.ps1
```

Нужны Windows, .NET SDK 8 и доступ к NuGet. Установленный AutoCAD для сборки не требуется: официальные библиотеки Autodesk используются только как зависимости компиляции. Скрипт выполняет проверки расчётов и структуры пакета и создаёт ZIP в `autocad/dist/`.

Для установки распакуйте весь ZIP и запустите `Install.cmd` при закрытых версиях AutoCAD. Инструкция и ограничения — в [README плагина](plugins/model-sheet-publisher/README.md).

Пакеты и журналы, созданные до выделения направления, остаются в прежних локальных `dist/` и `tmp/` корня репозитория. Новые результаты размещаются в каталогах этого направления.
