# Сверка общего установщика TrueBIM 0.2.39

Дата: 21.10.2026.

Установщик 0.2.39 содержит последние завершённые изменения ведомости отделки,
заполнятора арматуры 0.2.38 и ранее объединённого выпуска 0.2.35. Повторная
сборка не потребовалась: проверены существующий EXE, сохранённые бинарники
его сборки, исходники и содержимое поставки. Установщик не запускался.

SHA-256 `TrueBIM-Setup-0.2.39.exe`:
`6D1BF1F98E3586582764EB598EECF41E51C634FFD4D0BCA8B367E04A63ED978B`.

## Что объединено в main

- Ведомость отделки: этап назначения принадлежности, сохранение ручных
  исправлений, точные сообщения о ненайденных помещениях, обновлённая методичка.
- Заполнятор арматуры: запись выбранного параметра, режим пустых значений,
  выбор отдельных стержней, фильтр и сортировка по семейству/типу,
  сохранение выбора. Скрытые и неотмеченные строки не изменяются.
- Поддержка сборки против внешних Revit API 2019/2020 с проверкой версии;
  совместимость разбиения арматуры с API 2019.
- Сохранены ранее объединённые ТЭП, разбиение арматуры, электрические схемы,
  полный экспорт листа DWG, фильтры, сворачивание ВРС и остальные модули.

До сверки основной каталог содержал часть исходников заполнятора 0.2.37.
Их заменили проверенными исходниками 0.2.38 из рабочей копии, использованной
при сборке 0.2.39, включая новые тесты выбора. Версия установщика и его
документация в main приведены к 0.2.39.

## Доказательства состава

- SHA-256 обоих экземпляров EXE совпал с отчётом исходной сборки 0.2.39.
- Для Revit 2019–2026 бинарники совпали с SHA-256 из этого отчёта.
- Для каждой версии portable PDB подтвердил соответствие **703 исходных
  документов** текущему каталогу main. Покрыты все **702 файла C#** приложения.
- Дополнительно для каждой версии совпали **54 файла** модулей, иконок,
  Markdown-документации и README.
- **1048 файлов плагинов** в основном каталоге совпали со снимком исходников
  выпуска. Исходники заполнятора совпали с последним результатом завершённого
  чата «Уточнить требования к плагину КР».
- Изменения печати из архивного снимка `2d5a96f` уже присутствуют в main;
  переносить устаревшие общие файлы из него не потребовалось.
- В объединённом каталоге повторно пройдены **1166 тестов**, без ошибок
  и пропусков.

Машиночитаемый локальный отчёт:
`dist/installer/TrueBIM-Setup-0.2.39-consolidation-audit.json`.
Исходный отчёт сборки: `dist/installer/TrueBIM-Setup-0.2.39-verification.json`.
Логи, результаты тестов, RVT, DLL и EXE в Git не добавляются.

Нативные сценарии Revit повторно при этой сверке не запускались. Ранее
подтверждённые результаты и ограничения остаются в документации модулей:
отделка — Revit 2023; заполнятор — ограничения проверки записи и отсутствие
нативной проверки 2019. «Вернадского» сохраняется отдельным продуктом;
исследование САПФИР не добавляет несуществующую команду в общий установщик.
