# ИИ для проектировщиков: материалы для презентации

Подготовлено 9 сентября 2026 года для выступления перед проектировщиками и руководителями. Продолжительность — 30 минут: 26 минут рассказа и 4 минуты обсуждения.

**Главная мысль:** ИИ может сократить путь от конкретной проектной задачи до проверенного инструмента. Поэтому имеет смысл заново оценить автоматизацию, которую раньше откладывали из-за небольшого объёма, уникальности объекта или стоимости разработки.

Для проектировщика это возможность описывать правила и исключения своей работы и быстрее получать помощников под задачу. Для руководителя — возможность проверять небольшие инициативы на реальных данных и развивать те, которые дают измеримый эффект.

## Что установлено при обзоре

- В репозитории один продукт — модульная платформа TrueBIM для Revit. Это не набор из 21 отдельного установленного плагина.
- Текущая лента содержит 23 верхнеуровневые кнопки/меню. Если исключить настройки ведомости и открытие логов, остаётся 21 функциональное направление. Вложенные переключатели видимости и команды фасадов отдельно не подсчитываются.
- Платформа охватывает оформление и выпуск, параметры и проверки, координацию, библиотеку, геометрию, АР, КР и ЭОМ. Основной README описывает только часть возможностей.
- Многие операции реализованы как обычные алгоритмы Revit API. Само наличие автоматизации или распознавания изображения не доказывает использование генеративного ИИ внутри плагина.
- Есть документация процесса разработки с участием ИИ, но нет подтверждённого учёта доли ИИ в коде, экономии часов или сокращения сроков проектирования.
- В каталоге Dynamo найден только README. Сравнение с разработкой графов Dynamo — объяснительный сценарий, а не результат измерения существующих графов этого репозитория.

## Как использовать материал в выступлении

Покажите общую карту инструментов на одном слайде и подробно разберите три примера: проверка требований заказчика, оформление специфичных элементов и выпуск комплекта. Армирование используйте как пример более сложного следующего этапа. Полную техническую таблицу оставьте в приложении.

Предложенное название: **«ИИ в работе проектировщика: от ручной операции к своему инструменту»**.

Альтернативное название с акцентом для руководителей: **«Автоматизация под конкретный объект: как ИИ меняет стоимость разработки»**.

## Границы достоверности

Обзор выполнен по исходному коду, документации, структуре тестов и открытым первичным источникам. Revit в этой задаче не запускался; сборка, установка и тесты повторно не выполнялись. Исторические проверки обозначены как сведения из существующих отчётов. Учтены незакоммиченные изменения рабочей копии, прежде всего IsoField Rebar. Код плагинов не изменялся.

Любые часы в учебном примере — условные. Любые предлагаемые функции — идеи развития, если для них прямо не указан текущий источник реализации. Перед выступлением нужны актуальные снимки интерфейса и короткая репетиция выбранной демонстрации.
