# Направления проекта

- Задачи AutoCAD выполняются в `autocad/`. Перед такой работой прочитай `autocad/AGENTS.md` и README выбранного продукта.
- `plugins/`, `TrueBIM.sln`, `templates/` и `dynamo/` относятся к направлению Revit/Dynamo. У каждого продукта свои исходники, проверки и установочные пакеты.
- Если задача затрагивает несколько направлений, проверяй и описывай результат каждого отдельно. Не используй успешную проверку одного продукта как доказательство работоспособности другого.
- В коммиты включай только файлы текущей задачи. Сборки, временные данные, исходные пользовательские DWG/RVT и локальные SDK не добавляй в Git.
